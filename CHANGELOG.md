- Exact performance-estimation certificate checking, source/representation bindings, and finite-to-actual function bridges in Lean.

- Retained PG/GD certificates, one-step exact-pair results, regression inputs and the paper's fixed eight-configuration evidence.
- Locked dependency setup, quick/full verification entries, readable documentation and the structured manuscript.
- Fresh-directory export and a minimal arXiv source-packaging option. The public Git history will start independently of the private maintenance history.
- Confirmed Apache-2.0 licensing for project-owned software and separate CC-BY-4.0 licensing for the paper text, original figures and tables, TeX sources and PDF. Both license texts are included; the submission source package carries the paper license and scope statement.
