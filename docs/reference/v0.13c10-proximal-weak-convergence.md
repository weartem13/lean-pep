## Mathematical scope

For a real Hilbert space E, L>0, an L-smooth convex first-order pair f,g,
a convex real-valued h, and an existing global minimizer of f+h, the old
canonical proximal-gradient iteration converges weakly to some global
minimizer, whenever the old HasProx L h proof is supplied.

The analysis-facing `hilbertIterate_weak_tendsto` obtains this existence
from C7 when h is continuous. Its caller supplies neither HasProx nor a
run, nor a subgradient certificate, nor a compact orbit, nor a dimension
or separability assumption. Completeness and Continuous h are explicit.
The proximal parameter remains L (physical forward step 1/L).

The limit need not equal the reference minimizer used to bound the orbit.
No projection formula, quantitative weak-convergence rate, unconditional
norm convergence, inexact convergence or new PEP rate is claimed.
The functions and initial point are fixed throughout the infinite run;
horizon-dependent worst-case witnesses are not spliced together.

## 1. Use the standard weak topology

`HilbertWeakTopology.lean` does not replace any topology instance on E.
Public conclusions use mathlib's `toWeakSpace ℝ E` and `Tendsto`.
`weakSpace_tendsto_iff_dual` tests every continuous linear functional.
In a complete real inner-product space, `weakSpace_tendsto_iff_inner`
uses Riesz representation to obtain the equivalent tests against all v:E.

For the compactness argument only, define

    J(x) = StrongDual.toWeakDual (InnerProductSpace.toDualMap ℝ E x).

Its evaluations are exactly J(x)(v)=inner ℝ x v. Riesz surjectivity and
isometry identify J''closedBall center R with the preimage under
WeakDual.toStrongDual of the corresponding norm ball in StrongDual.
`WeakDual.isCompact_closedBall` is the existing Banach-Alaoglu theorem.
This produces weak-star compactness of the represented ball, NOT norm
compactness. Completeness is needed to identify its cluster points with
actual vectors of E.

The proof uses compact FILTERS. It does not call a weak-dual sequential
compactness theorem and does not need SeparableSpace E. A cluster point
J(z) of J(u_n) supplies the nontrivial finer filter

    l = comap (fun n => J(u_n)) (nhds (J z)) ∩ atTop,

where the displayed intersection denotes filter infimum. The source
proves l.NeBot, l ≤ atTop, and convergence of every pairing along l.
A constant index selection or the bottom filter is not a valid substitute.

Main interfaces:

    weakSpace_tendsto_iff_dual
    weakSpace_tendsto_iff_inner
    weakSpace_tendsto_of_tendsto
    weakRiesz_closedBall_image
    isCompact_weakRiesz_closedBall
    inner_subfilter_of_weakRiesz_cluster

## 2. Bounded demiclosedness without assuming weak continuity of T

`WeakFejerConvergence.lean` is independent of optimization functions,
prox maps, PEP models and certificates. Suppose T is nonexpansive.
For arbitrary x,z and B ≥ ||x-z||, it proves the scalar estimate

    ||Tz-z||² ≤ 2 <x-z,Tz-z> + 2B ||Tx-x|| + ||Tx-x||².

Indeed ||x-Tz|| ≤ ||Tx-x||+||x-z||; expand the square on the left and
use ||x-z||≤B in the cross term. If u tends weakly to z along a nontrivial
filter, its distances to z are uniformly bounded by B, and
||T(u)-u|| tends to zero, the right side tends to zero. Thus Tz=z.

Uniform boundedness is explicit in the generic demiclosedness interface.
For cluster points of the algorithm it is derived from a Fejer ball
around a known minimizer, followed by the triangle inequality. No new
boundedness premise is exposed by the final algorithm theorem.

No norm-continuous nonlinear map is passed through a weak limit. Even
nonexpansiveness alone would not justify such a passage.

Main interfaces:

    fixed_defect_bound
    fixed_of_inner_tendsto_of_residual
    fixed_of_weakRiesz_cluster

## 3. Opial-type uniqueness and convergence of the whole sequence

The exact squared-distance identity is

    ||x-z||²-||x-w||² = 2 <x,w-z> + ||z||²-||w||².

A difference of squared distances therefore has a limit along any weakly
convergent filter; this does NOT assert weak continuity of a norm.

For two weak cluster points z,w that are fixed, Fejer monotonicity makes
both ||u_n-z|| and ||u_n-w|| antitone and bounded below. They have scalar
limits along the original atTop filter, so the difference of their squares
has a single scalar limit along every finer nontrivial filter. Weak
convergence to z identifies it as -||z-w||²; convergence to w identifies
it as +||z-w||². Hence z=w.

Distances to BOTH cluster points are used. Distance monotonicity only to
one reference point would not suffice. Once the represented orbit lies
in a weakly compact ball, its unique cluster point attracts the entire
image filter by `IsCompact.tendsto_nhds_of_unique_mapClusterPt`.
The pairing equivalence then gives standard WeakSpace convergence.

Main interfaces:

    distance_sq_difference
    distance_sq_difference_tendsto
    inner_limits_eq_of_antitone
    weakRiesz_clusters_eq
    exists_weak_tendsto_fixed
    eq_of_strong_and_weak_limits

The generic theorem requires a fixed point, Fejer monotonicity to every
fixed point, and vanishing residuals. It does not assume that T is weakly
continuous or that the orbit is norm-compact.

## 4. Reuse the existing optimization chain

`ProximalGradientWeakConvergence.lean` uses only the original objects:

    C8 nonexpansiveness / Fejer monotonicity / residual decay
    -> bounded demiclosedness and weak compactness
    -> weak convergence to a fixed point
    -> C5 fixed point iff ordinary composite minimizer.

C7 discharges HasProx for continuous convex h. C6 run uniqueness connects
an external coherent infinite run to the same iterate. No recursive
algorithm or new prox selection function is defined in C10.

provides a strong limit, the new compatibility theorem identifies it
with any supplied weak limit; it does not prove weak implies strong.
