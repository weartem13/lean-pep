## Generic actual-run scaling

`MomentumScaling.lean` reuses `MomentumActual.state/query` with the existing
`ParametricGDScaling.normalizedGradient L g`. The physical updates are

```text
x_(k+1) = y_k - (alpha_k/L) g(y_k)
y_(k+1) = x_(k+1) + beta_k (x_(k+1) - x_k).
```

Neither the rational schedule nor the compiled model is changed. In particular,
`beta_k` is not divided by L and oracle calls remain at the query.
`IsSmoothRun` is a transparent abbreviation of the existing `IsRun` contract;
`isSmoothRun_of_updates` accepts these ordinary physical equations, and
`eq_of_isSmoothRun` reuses the original uniqueness theorem.

### Affine trajectory transport

For T(z) = center + R z, if g'(T z) = R g(z), then

```text
state s g' (T z0) k = T (state s g z0 k)
query s g' (T z0) k = T (query s g z0 k).
```

`isRun_affine` transports the ordinary run equations, and `affine_trajectory`
uses `MomentumActual.eq_of_isRun`. This structural result works for every
index, every rational schedule, and signed or zero R. It assumes the displayed
field relation, not smoothness or invertibility. It does not assert a rate for
an arbitrary schedule.

### Positive L,R normalization

The existing `SmoothScaling` objects are reused without new function-class
semantics:

```text
F(z) = (f(xStar + R z) - f(xStar))/(L R^2)
G(z) = g(xStar + R z)/(L R)
z0   = (x0 - xStar)/R.
```

`normalized_trajectory` proves simultaneous state/query transport, while
`normalizedInitial_normSq` and `normalizedInitial_radius` transport the initial
norm inequality. `SmoothScaling.normalizedFirstOrder` supplies the normalized
first-order contract.

For a certificate c on `outputModelQ N s unitRadiusNormalizationQ`, the theorem
`certificate_upper` requires BOTH

```text
GramPEP.checkUpperCertQ c = true
c.objective = outputObjectiveQ N s unitRadiusNormalizationQ.
```

Under actual L-smooth first-order assumptions, L>0, R>=0, stationarity and
||x0-xStar||^2 <= R^2, its conclusion is

```text
f(smoothState s L g x0 N) - f(xStar) <= L R^2 * c.bound.
```

The positive-radius branch applies the unchanged B2 certificate theorem to
F,G,z0. The zero-radius branch proves x0=xStar and uses `stationary_trajectory`;
it does not divide by R or assume a positive radius. There is no additional
nonnegativity assumption on c.bound. The zero-radius product is zero regardless.

Wrappers provide exact initial distance, the analytic contract, and externally
defined runs. The generic theorem ranges over N and schedules but still needs
the corresponding accepted, objective-matched certificate.

## The four-step pilot

`NesterovPilotScaling.lean` instantiates the same B1 certificate and the same
schedule alpha_k=1, beta_k=k/(k+3). The real physical step is 1/L.
`iterate_one` and `query_one` identify L=1 with the passed B2 definitions.

The new upper theorem is

```text
f(iterate L g x0 4) - f(xStar) <= L R^2 / 21.
```

The first-order theorem needs only a real inner-product space. Its analytic
wrapper uses any real Hilbert space. Callers need not supply Gram feasibility
or unproved trajectory-realization assumptions. The output remains x_4, not y_4.

## Actual scaled lower witness

`NesterovPilotWitnessScaling.lean` defines

```text
a = R * (2/21)
F_L,R(x) = L * H_a(x)
G_L,R(x) = L * min(x,a),
```

where H is the existing one-sided Huber function. It exposes
`HuberWitness.amplitudeScaled_analytic L a` by specializing the already verified
scaled Huber family at index zero, whose normalized threshold is one. This is
only a reuse of arbitrary-threshold regularity: no GD trajectory or rate is
used as a Nesterov proof.

`scaled_trajectory` applies the generic affine theorem to the actual B3 witness.
It holds for every index and includes R=0; only the attainment claim is restricted
to four steps. At that horizon,

```text
x_4 = R * 23/42,   y_4 = R * 10/21,
F_L,R(x_4)-F_L,R(0) = L R^2 / 21,
F_L,R(y_4)-F_L,R(0) = 2 L R^2 / 49.
```

The endpoint-inequality theorem requires R>0. At R=0 both points are zero;
the function itself is not asserted to be identically zero away from the run.
Stationarity, global minimality, radius feasibility, and attainment are packaged
by `analytic_lower_witness`. An external-run attainment wrapper is included.

`oneDimensionalAnalyticValues L R` quantifies genuine functions/gradients,
stationarity, the radius inequality, and the physical actual recurrence. It has
no finite Gram or certificate assumption. `oneDimensional_analytic_tight` proves
in source that L R^2/21 is its greatest element, using this witness for membership
and the scaled upper theorem for the upper bound. The combined theorem packages
an arbitrary Hilbert-space upper bound with one-dimensional actual tightness;
no cross-universe supremum object is defined.
