# v0.12B12 off-diagonal ordered quadratic cancellation

Status: kernel-verified with Lean 4 / mathlib v4.31.0.  The user-local
aggregate build completed successfully with 3209 jobs and
`tests/lean/smoke/V12B12SmokeTest.lean` exposed the complete ordered off-diagonal theorem
surface.

## Baseline

v0.12B11 is kernel-verified.  It proves that every ordered sampled-gradient
quadratic coefficient of the generated certificate is

```text
gdQuadraticInterpSumQ N r s + gdQuadraticSquareSumQ N r s,
```

and that the target coefficient is zero.  This slice closes all entries with
`r != s` without changing the generated certificate or the generic checker.

## Symmetry

The module proves symmetry for:

```text
slackPolyQ
interpPolySumQ
squarePolySumQ
gdQuadraticInterpSumQ
gdQuadraticSquareSumQ.
```

The ordered representation remains explicit; symmetry is proved rather than
used to replace ordered entries by an unordered storage convention.

## Interpolation contribution

For `r < s`, a star-to-iterate slack contributes `-1/2` only when the iterate
index is `s`.  Consecutive-iterate slacks have no strictly off-diagonal
quadratic coefficient.  Therefore

```text
gdQuadraticInterpSumQ N r s = -(1/2) * gdStarWeightQ N s.
```

## Square contribution

For `r < s`, each generated reverse-LDL square contribution satisfies

```text
gdQuadraticSquareContributionQ N r s k
  = -(1/2) * gdGradientSquareContributionQ N s k.
```

The proof uses the triangular factor support established in v0.12B9.  Summing
over all factors gives

```text
gdQuadraticSquareSumQ N r s
  = -(1/2) * gdGradientSquareSumQ N s.
```

## Cancellation

v0.12B10 already proves

```text
gdStarWeightQ N s + gdGradientSquareSumQ N s = 0.
```

Multiplying this identity by `-1/2` closes every strict upper-triangular
quadratic entry.  The proved symmetry then closes the opposite ordered entry.
The public pointwise results are:

```text
gdQuadraticCoefficientIdentityQ_of_lt
gdQuadraticCoefficientIdentityQ_offDiagonal
gdCertificate_quadCoeff_of_ne
gdCertificate_quadCoefficients_offDiagonal.
```

## Remaining work

Diagonal entries are the only unresolved coefficient family after B12.  The
v0.12B13 candidate proves those entries vanish for every `N` and sampled-gradient
index, assembles the full `QuadPolyQ` identity, proves arbitrary-`N` checker
acceptance, and derives the normalized finite-GD upper theorem

```text
f_N <= 1 / (4 * N + 2).
```

That finite upper theorem will still require the actual-function trajectory
bridge and general scaling layer before it becomes an arbitrary-`N` theorem
for actual smooth convex functions.  A matching actual lower witness or
interpolation completeness remains necessary for a tight worst-case claim.
