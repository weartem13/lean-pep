## Affine-branch invariant

Let

```text
q_N = threshold N = 1 / (2N + 1).
```

For every `k <= N`, D2 proves:

```lean
threshold_le_witnessPoint N k hk :
  q_N <= z_k
```

and therefore:

```lean
witnessGradient_witnessPoint N k hk :
  witnessGradient N z_k = q_N
```

The actual GD update is consequently:

```text
z_(k+1) = z_k - witnessGradient N z_k = z_k - q_N.
```

## Exact final value

The final point is proved to satisfy:

```text
z_N = (1 + q_N) / 2.
```

Because this point lies on the affine Huber branch,

```text
H_N(z_N) = q_N * z_N - q_N^2 / 2 = q_N / 2.
```

The already verified rational identity


give:

## Boundary

D2 itself does not prove:

- `HasDerivAt`/`HasGradientAt` for the piecewise function;
- `LipschitzWith 1` for `huberGradient`;
- membership in `IsOneSmoothConvexAnalytic`;
- general positive-`L`, radius-`R` lower-witness scaling; or
- the final tight theorem stated entirely in the general analytic API.

v0.12D3 now implements the analytic-regularity obligations as a separate
source candidate without changing any D1 or D2 trajectory formula.
