## Purpose of this slice

The scalar polynomial identity contains more information than a theorem about
one-dimensional numbers.  Its coefficients can be interpreted against any
real Hilbert-space Gram data:

* `constCoeff` multiplies `inner u0 u0`, where `u0` is the initial centered
  displacement;
* `gradCoeff i` multiplies `inner u0 (g i)`;
* `valueCoeff i` multiplies the centered function value `f_i - f_star`; and
* `quadCoeff i j` multiplies `inner (g i) (g j)`.

The new module is:

```text
LeanPEP/ActualFunction/ParametricGDHilbert.lean
```

## Vector and polynomial semantics

`evalVector` realizes a rational affine gradient form as

```text
constCoeff * u0 + sum_i gradCoeff_i * g_i.
```

`evalHilbert` evaluates a `QuadPolyQ` against `u0`, sampled gradients, and
sampled function values.  The verified module proves exact semantics for:

```text
GradAffineQ.zero/const/basis/add/neg/sub/scale
QuadPolyQ.zero/add/neg/sub/scale/valueVar/mulAffine/square
xAffineQ
gradAffineQ
slackPolyQ
interpPolySumQ
squarePolySumQ
certificateRhsPolyQ
upperTargetPolyQ
```

In particular, `QuadPolyQ.mulAffine` becomes the actual ambient inner product
of the two represented vectors, and `QuadPolyQ.square` becomes an actual
squared norm.

## Generated trajectory semantics

For an initial displacement `u0` and sampled gradients `g_0,...,g_N`, the
centered generated positions are

```text
x_star = 0
x_k = u0 - sum_{t < k} g_t.
```

The verified module defines all ordered Hilbert interpolation slacks on
these points and proves that `slackPolyQ` evaluates to exactly those slacks.

## Abstract Hilbert upper theorem

The main verified theorem is:

```lean
gd_upper
    (N : ℕ)
    (u0 : E)
    (grad : Fin (N + 1) → E)
    (value : Fin (N + 1) → ℝ)
    (hfeasible : Feasible u0 grad value) :
    value (gdObjective N) ≤
      (gdBoundQ N : ℝ) * inner ℝ u0 u0
```

A norm-squared presentation is also provided:

```lean
gd_upper_normSq ... :
  value (gdObjective N) ≤
    (gdBoundQ N : ℝ) * ‖u0‖ ^ 2
```

The proof uses the already verified B13 certificate identity and weight
nonnegativity.  Interpolation terms are nonnegative by the supplied abstract
feasibility hypothesis; square terms are nonnegative because they are actual
ambient squared norms.

## Boundary

The Hilbert interpretation itself is now kernel-verified.  It does not by
itself claim that the abstract samples come from an actual smooth-convex
function.  v0.12C2 is the separate candidate bridge that:

1. defines an arbitrary-length actual unit-step GD path;
2. proves its centered positions equal the generated prefix form;
3. instantiates gradients and centered function values from the actual
   function;
4. derives every ordered interpolation inequality from the already verified
   analytic/first-order bridge; and
5. applies `gd_upper_normSq`.

General `L,R` scaling remains a subsequent transport step after C2.  A
matching actual lower witness or interpolation completeness remains necessary for a tight
actual-function worst-case theorem.
