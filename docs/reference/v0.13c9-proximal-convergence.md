## What changes mathematically

C8 established nonexpansiveness of the existing forwardBackwardStep, Fejer
monotonicity, and decay of its residual along the original iterate. Those
facts alone were not labeled point convergence. C9 closes point convergence
in finite-dimensional real inner-product spaces, where the Fejer ball is
compact. A separate general-Hilbert result establishes objective-value
convergence directly from the existing sharp finite-time certificate.

No algorithm, proxMap choice, profile, Gram datum, certificate, checker,
finite-time constant, external schema, importer, or witness is redefined.

## 1. Metric-space Fejer lemma

The independent file FejerConvergence.lean has four theorems.

* If dist(u_n,z) is antitone and some sequence of sampled indices approaches z,
  the full sequence approaches z. For epsilon>0, choose K with
  dist(u_(phi K),z)<epsilon and use antitonicity for every n>=phi K.
  Cofinality is not needed for this particular implication.
* If T is continuous, dist(T(u_n),u_n)->0, and a COFINAL sampled subsequence
  tends to z, then T(z)=z. The same distance along that subsequence converges
  both to dist(T(z),z) and to zero; uniqueness of real limits identifies them.
* If distance to EVERY fixed point is antitone, combine the preceding two
  facts to obtain a fixed point and convergence of the whole sequence.
* A compact containing set gives a strictly increasing convergent subsequence
  via mathlib IsCompact.tendsto_subseq, so the last implication yields a limit.

This layer requires a metric space, not a vector space, completeness, a
minimizer, or a proximal algorithm. Its compactness premise is never replaced
by bare boundedness in an infinite-dimensional space.

## 2. Existing PG iteration converges in finite dimension

Let T(x)=proxMap(x-g(x)/L), with exactly the definitions of C6/C8. C8 supplies
continuity of T and residual decay. C5/C8 identify fixed points of T with
ordinary global minimizers of f+h. For every such minimizer z, C8 supplies
antitonicity of ||x_k-z||, not just for the original reference point.

The conditional theorem iterate_tendsto_of_subsequence works in an arbitrary
real inner-product space once a norm-convergent cofinal subsequence is supplied.
The compact-orbit theorem retains compact containment as an explicit premise.

For finite dimension, fix a supplied ordinary minimizer xStar. C8 gives

    ||x_k-xStar|| <= ||x0-xStar||.

The corresponding closed ball is compact, including radius zero and dimension
zero. Extract a subsequence, identify its limit as a minimizer, and promote it
to convergence of the full sequence by the metric-space lemma.

The automatic public interface is finiteDimensionalIterate_tendsto. It assumes
L>0, the actual L-smooth convex function/gradient contract, whole-space real
convex h, and an ordinary composite minimizer. It returns

    exists z, (forall y, f(z)+h(z) <= f(y)+h(y))
              and Tendsto (finiteDimensionalIterate ... x0) atTop (nhds z).

There is no caller-supplied trajectory, HasProx, continuity of h, subgradient
witness, Gram feasibility, uniqueness of minimizers, or radius parameter.
C6 supplies prox existence. The first-order variant does not use the analytic
bridge. The analysis-facing variant simply supplies hf.toFirstOrder.

The limit is SOME minimizer, not necessarily the supplied xStar. For example,
f(x,y)=x^2/4, h=0, L=1 gives x_k=(2^(-k)*x0,y0). A reference minimizer (0,0)
need not be the limit (0,y0). The extra theorem ..._tendsto_of_unique requires
an explicit unique-minimizer hypothesis to identify the limit with xStar.

External infinite runs are handled through the already proved run_eq_iterate:
the premise is one sequence satisfying IsSmoothProxRun N for EVERY N. A single
finite run cannot justify a limit theorem. The Hilbert wrapper with a compact
orbit keeps compactness explicit; the finite-dimensional Hilbert wrapper
uses C7's equality of whole sequences with the C6 construction.

## 3. Objective convergence is a separate proof

For one fixed function pair and initial point, put

    gap_k = f(x_k)+h(x_k) - (f(xStar)+h(xStar)),
    C = L*||x0-xStar||^2/4.

Global minimality supplies gap_k>=0. The unchanged C5 supplied-run upper
interface, backed by the original C3B certificate, supplies

    gap_(k+1) <= C/(k+1).

A reusable scalar helper passes this bound to the limit and then restores the
unshifted sequence by a tail argument. No positive-time upper formula is applied
to time zero. Adding the optimum value gives convergence of objective values.

The supplied-run interface does not require total prox solvability away from
the orbit. The canonical interface uses C6's run proof. The Hilbert interface
uses C7's proved existence and explicitly retains Continuous h; it does not
require finite dimension, compactness, or convergence of the points.

This is a consequence of the existing sharp finite-time objective bound, not
a new rate or a new certificate. The proof of strong convergence is independent
of this value-limit proof. Both use the same unchanged actual iteration.

## Scope and non-claims

* No unconditional norm convergence in arbitrary infinite-dimensional Hilbert
  spaces, and no weak-convergence theorem, is claimed by C9.
* No rate of point convergence, unique optimizer, or nearest-minimizer selection
  is asserted. Existence of some global minimizer remains an explicit premise.
* No convergence theorem for inexact runs or summable errors is added.
* h remains a whole-space real-valued convex function; no indicator functions
  or extended-real domains, variable steps, or missing-minimizer cases are added.
* A fixed old witness function is followed by its actual canonical iteration.
  Its old linear formula was only certified on a finite prefix. The tests verify
  the actual nonnegative branch reaches zero later, rather than extending the
  linear formula into a false infinite trajectory.
* The old LR^2/(4T) exact finite-time tightness remains unchanged. The lower
  witness family depends on T; none of the new limit theorems varies the function
  with the iteration index.
