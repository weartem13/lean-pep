## 2. Four multiplier families

Let delta^f_(i,j) and delta^h_(i,j) denote the OLD compiler's ordered slacks:
value_i - value_j - support at j, with the gradient-square correction only for f.
Write X_i = x_i-x_star. Define b_T = 1/(4T).

Smooth star multipliers (i=0,...,T):

    alpha_0 = 1/(2T)
    alpha_i = (2T+1)/((2T-i)(2T-i+1)),  1 <= i < T
    alpha_T = 1/(T+1)

Smooth consecutive multipliers (i=0,...,T-1):

    beta_i = (i+1)/(2T-i)

Nonsmooth star multipliers (j=1,...,T):

    lambda_j = 2T/((2T-j)(2T-j+1))

Nonsmooth consecutive multipliers (j=1,...,T-1):

    mu_j = j/(2T-j)

Use alpha_i on delta^f_(star,i), beta_i on delta^f_(i,i+1),
lambda_j on delta^h_(star,j), and mu_j on delta^h_(j,j+1).
The radius assumption gets b_T. This is 4T+1 positive assumption terms.

Their indices are built against the actual C2 assumption length with proved
bounds; no list wrapping or silent default indexing is used. `smoothIndex`
and `nonsmoothIndex` preserve the two row-major component blocks.

## 3. Explicit rational sum-of-squares matrix

For i=0,...,T-1, set

    D_i = T + i(2T-i-1)
    A_i = D_i/(2T-i)^2
    r_i = (2T-i)/(2T-i-1)
    c_i = (i+1)(2T-i)/(2D_i)
    e_i = i(i+1)(2T-i-1)/(4D_i(2T-i)).

The dual matrix is the weighted outer-product sum of three groups:

    A_i * [X_i - r_i X_(i+1) - c_i (g_i-g_(i+1))]^2,
    (alpha_i/2) * [g_i-g_star]^2,
    e_i * [g_i-g_(i+1)]^2.

The middle group runs i=0,...,T. The other groups run i=0,...,T-1.
Here squares denote rank-one coefficient-vector factors interpreted in the
Gram matrix. There are 3T+1 listed factors, including the deliberately retained
zero-weight e_0 factor. All other weights are positive.

For i<T, 2T-i-1 >= T > 0, and D_i > 0. C3A's source proves the needed
rational nonnegativity and the existing PSDFactorValidQ proposition for every n.
The factor matrix identity is true by its construction, not by tolerance.
There is no numerical eigendecomposition or generic LDL synthesizer in the
final candidate construction.

The intended coefficient identity is:

    b_T - ((f_T+h_T)-(f_star+h_star))
      = sum alpha_i delta^f_(star,i)
        + sum beta_i delta^f_(i,i+1)
        + sum lambda_j delta^h_(star,j)
        + sum mu_j delta^h_(j,j+1)
        + b_T (1-||X_0||_G^2)
        + <dualMatrix,G>.

`upperCertQ_check_iff_identity` reduces unrestricted checker acceptance to
precisely this equality of LinearExprQ coefficient objects. It is not itself
an unconditional all-horizon rate theorem.

## 4. Algebraic derivation and the remaining formal step

Independent symbolic algebra checks 14 local identities. With the interior
weight formulas extended as rational expressions, examples are

    alpha_i = beta_i-beta_(i-1),
    lambda_i = mu_i-mu_(i-1),
    2 A_i r_i = lambda_(i+1)+2 mu_i,
    A_i + A_(i-1) r_(i-1)^2 = lambda_i+mu_(i-1)+mu_i,
    2 A_i c_i = beta_i,
    2 A_i r_i c_i = lambda_(i+1)+mu_i,
    beta_i/2 - A_i c_i^2 = e_i.

Initial and terminal identities are checked separately, including A_0=1/(4T)
and A_(T-1)r_(T-1)^2=1. Value flow cancels internal function slots. Substituting
s_(i+1)=X_i-X_(i+1)-g_i leaves a block-tridiagonal quadratic expression in
positions and shifted gradients g_i-g_star; the identities above explain its
three-factor-group decomposition. This is the derivation behind the formulas,
not an inference from a fitted table of floating-point solutions.

These symbolic checks are external evidence. The remaining Lean task is to
connect the row-major list lookups and their weighted sums to these local
coefficient identities, with exact finite-sum reindexing and both endpoints,
and derive `CertificateIdentityQ n` for every n. C3A does not add that theorem.

The initial exploratory exact LDL calculation (included in the validation
bundle) also accepted T=1,...,12, but the delivered formula avoids LDL and

## 5. Actual lower witness for every T

Reuse C1's verified smooth f(x)=x and g(x)=1. Set

    a_T = 1/(2T)
    h_T(x) = a_T max(x,0)-x
    x_star=0, x_k=1-k*a_T, 0 <= k <= T.

The new source proves h_T convex, star subgradient -1, and affine-branch
subgradient a_T-1 at every nonnegative point. All points of the required run
satisfy x_k>=1/2. The residual is exactly

    x_k-g(x_k)-x_(k+1) = a_T-1.

C1's prox optimality theorem therefore gives an actual IsProxRun T, not merely
a feasible finite datum. The endpoint and composite gap are

    x_T=1/2,
    f(x_T)+h_T(x_T)-(f(0)+h_T(0)) = 1/(4T).

The linear trajectory definition is not asserted to give a prox run beyond
this prefix. The actual functions are globally defined; no indicator-valued
or extended-real function is used. The smooth gradient at the minimizer stays
nonzero, demonstrating the required component cancellation.

`bound_mem_analyticValues` gives membership in the EXISTING C2 actual value
set for every n. `bound_mem_finiteValues` transports the same actual run into
the EXISTING finite value set. Both are lower conclusions, without upper
checker premises and without interpolation completeness.
