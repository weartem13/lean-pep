# v0.12B8 arbitrary-`N` gradient-linear coefficient reduction

## Scope

v0.12B5 kernel-verified all function-value coefficients, and v0.12B7
kernel-verified the complete constant coefficient for every trajectory length.
This slice isolates the next polynomial channel: coefficients linear in the
sampled gradients.

It does not change the generated certificate, interpolation multipliers,
affine-square factors, checker, or finite-GD semantics.

## Interpolation contribution

For one symbolic interpolation slack, only

```text
-g_j * (x_i - x_j)
```

can contribute a gradient-linear coefficient.  Function-value variables carry
no gradient coefficient, and the square `(g_i - g_j)^2` has zero affine
constant.

All symbolic iterates have affine position constant `1`, while the optimum has
constant `0`.  Consequently:

```text
slack(star, iter k).gradCoeff r = unitCoeff k r
slack(iter i, iter j).gradCoeff r = 0
```

Therefore the complete interpolation list contributes exactly
`gdStarWeightQ N r` at sampled gradient index `r`; the consecutive-chain list
contributes zero.

## Square contribution

For an affine form `a = c + b · g`, its square has linear coefficient
`2 * c * b_r` at gradient index `r`.  The slice defines

```text
gdGradientSquareContributionQ N r k
  = gdSquareWeightQ N k
      * 2
      * (gdSquareFormQ N k).constCoeff
      * (gdSquareFormQ N k).gradCoeff r
```

and the complete finite sum

```text
gdGradientSquareSumQ N r.
```

The generated certificate coefficient is then reduced exactly to

```text
gdStarWeightQ N r + gdGradientSquareSumQ N r.
```

The target polynomial `gdBoundQ N - f_N` has gradient-linear coefficient zero.

## Remaining identity

The pointwise residual obligation is exposed as

```text
gdGradientCoefficientIdentityQ N :=
  forall r,
    gdStarWeightQ N r + gdGradientSquareSumQ N r = 0.
```

The module proves that equality of all generated and target gradient-linear
coefficients is equivalent to this family.  It also derives the reduced family
for the existing checker-verified regressions `N = 0`, `N = 4`, and `N = 8`.

This reduction is now kernel-verified.  v0.12B9 exposes the exact support
pattern of every generated square factor and rewrites the finite sum as one
diagonal contribution minus twice a strict suffix of the already verified
constant contributions.  That suffix telescope remains to be closed for
arbitrary `N`.  Ordered gradient-quadratic coefficients remain a separate
final polynomial channel, so universal checker acceptance is not yet claimed.
