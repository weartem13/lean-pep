## Purpose of this slice

C3 transports the verified normalized theorem to a positive general

```text
LeanPEP/ActualFunction/ParametricGDScaling.lean
```

No new PEP certificate is generated.  The same B13 certificate and C2 actual
trajectory theorem are reused unchanged.

## Smoothness normalization

The verified module defines

```lean
normalizedFunction L f x = (f x - f 0) / (L : Real)
normalizedGradient L g x = (L : Real)⁻¹ • g x.
```

The additive constant `f 0` has no effect on first-order models or function
value gaps.  By specializing the already verified B1 scaling theorem to
center `0` and spatial scale `1`, C3 proves

```lean
normalizedFirstOrder :
  IsSmoothConvexFirstOrder L f g ->
  0 < (L : Real) ->
  IsOneSmoothConvexFirstOrder
    (normalizedFunction L f)
    (normalizedGradient L g).
```

## Step-size-`1/L` recursion

The actual general-smoothness recursion is

```lean
smoothGDIterate L g x0 0 = x0
smoothGDIterate L g x0 (k + 1) =
  smoothGDIterate L g x0 k
    - (L : Real)⁻¹ • g (smoothGDIterate L g x0 k).
```

It is defined as the C2 unit-step recursion applied to
`normalizedGradient L g`, so the trajectory transport is definitionally
exact.

## Verified theorems

For the general first-order contract, C3 provides

```lean
IsSmoothConvexFirstOrder.parametricGD_upper_exact_radius
IsSmoothConvexFirstOrder.parametricGD_upper_radius
IsSmoothConvexFirstOrder.parametricGD_upper_unit_radius
```

The main radius-bounded conclusion is

```text
f (smoothGDIterate L g x0 N) - f xStar
  <= (L : Real) * R^2 * (gdBoundQ N : Real),
```

under

```text
0 < (L : Real)
g xStar = 0
||x0 - xStar||^2 <= R^2.
```

Since `gdBoundQ N = 1 / (4N + 2)`, this is precisely

```text
f(x_N) - f(xStar) <= L * R^2 / (4N + 2).
```

The analysis-facing structure receives matching corollaries:

```lean
IsSmoothConvexAnalytic.parametricGD_upper_exact_radius
IsSmoothConvexAnalytic.parametricGD_upper_radius
IsSmoothConvexAnalytic.parametricGD_upper_unit_radius
```

## Boundary

C3 is a universal upper theorem only.  It does not prove that the upper bound
is attained by an actual smooth-convex function.  A parameterized actual
Huber-type lower witness or a general interpolation-completeness theorem is
still required before claiming a tight actual-function worst-case result.
