# v0.12B2 closed-form finite-GD certificate generator

## Scope

This slice starts the arbitrary-trajectory-length upper-certificate milestone.
It does not yet claim a universal theorem quantified over every `N`.

The Lean constructor

```text
ParametricUpper.gdUpperCertQ N
```

generates an `UpperCertQ N` with target bound

```text
1 / (4*N + 2).
```

It uses the same exact rational coefficient checker and the same real
soundness theorem as the previously hand-written `N = 1,2,3` certificates.

## Interpolation flow

For `k < N`, define

```text
c_k = (k+1)/(2*N-k).
```

The consecutive interpolation pair `(k,k+1)` receives weight `c_k`.
The star-to-iterate weights are the successive increments of this flow after
setting `c_N = 1`:

```text
a_0 = c_0,
a_k = c_k-c_(k-1),
a_N = 1-c_(N-1).
```

The implementation uses the equivalent closed form

```text
a_k = (2*N+1)/((2*N-k)*(2*N-k+1))   for k < N,
a_N = 1/(N+1).
```

These weights cancel every function-value coefficient except `-f_N`.

## Closed-form SOS remainder

Let

```text
q = 1/(2*N+1),
h_k = g_k-q.
```

For each `k = 0,...,N`, the generated affine factor is

```text
z_k = h_k + (1/(2*N-k+1)) * sum_{r<k} h_r.
```

The weights are the diagonal entries of a reverse-order rational LDL
factorization.  The last factor has weight `1/2`; for `k < N` the weight is

```text
(2*k*(2*N-k) + 2*N + 1) / (2*(2*N-k)^2).
```

All data are exact rationals.  No floating eigenvector, tolerance, or external
factorization result is trusted.

## Verified boundary

The constructor is parameterized for every natural `N`.  Lean 4 / mathlib
v4.31.0 has now executed the unchanged checker successfully on the concrete
generated instances `N = 0,...,8`; the smoke test applies the accepted `N = 4`
and `N = 8` certificates to arbitrary feasible real data.

v0.12B3 next proves all generated weights nonnegative uniformly and reduces
the remaining symbolic task to

```text
checkUpperCertQ (gdUpperCertQ N) = true
```

for every `N`.  The finite sweep is a regression and formula-validation layer,
not a substitute for that universal theorem.  No exact actual-function
worst-case statement follows without a matching lower witness or interpolation
completeness.
