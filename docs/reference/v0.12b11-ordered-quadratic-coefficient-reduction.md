# v0.12B11 ordered gradient-quadratic coefficient reduction

Status: kernel-verified with Lean 4 / mathlib v4.31.0.  The user-local
aggregate build completed successfully with 3208 jobs and the dedicated
`tests/lean/smoke/V12B11SmokeTest.lean` exposed the full ordered-quadratic reduction surface.

## Scope

v0.12B10 is kernel-verified.  It closes every sampled-gradient-linear
coefficient of the closed-form arbitrary-length GD certificate.  The only
remaining coefficient family in the generated quadratic polynomial is the
ordered sampled-gradient-quadratic matrix.

This slice isolates that final family without changing certificate data,
interpolation multipliers, square weights, reverse-LDL factors, the generic
checker, or finite-GD semantics.

## Generic coefficient projections

For one interpolation slack, the ordered quadratic coefficient is projected as

```text
-symOuter(gradient_j, position_i - position_j)
- (1/2) * symOuter(gradient_i - gradient_j,
                   gradient_i - gradient_j).
```

The module proves that projection commutes with weighted interpolation lists
and list concatenation.

For an affine form

```text
a = c + sum_r b_r g_r,
```

its square has ordered quadratic coefficient `b_r * b_s`.  Therefore a
weighted square list contributes

```text
sum_t t.weight * t.form.gradCoeff r * t.form.gradCoeff s.
```

## Generated finite sums

The slice defines two exact rational quantities:

```text
gdQuadraticInterpSumQ N r s
gdQuadraticSquareSumQ N r s.
```

The first is the complete generated interpolation contribution at ordered
matrix entry `(r,s)`.  The second is the complete reverse-LDL square
contribution.  The generated certificate coefficient is proved to be their
sum:

```text
certificate.quadCoeff r s
  = gdQuadraticInterpSumQ N r s
      + gdQuadraticSquareSumQ N r s.
```

The target polynomial `gdBoundQ N - f_N` has no sampled-gradient-quadratic
term, so the remaining pointwise obligation is

```text
gdQuadraticInterpSumQ N r s
  + gdQuadraticSquareSumQ N r s
  = 0.
```

This family is named `gdQuadraticCoefficientIdentityQ N`.

## Checker compatibility

The module proves that equality of every generated and target ordered
quadratic coefficient is equivalent to `gdQuadraticCoefficientIdentityQ N`.
It also derives the reduced identity for `N = 0`, `4`, and `8` from the
already kernel-verified complete checker identities.

## Remaining work

This slice does not itself prove the pointwise finite sums vanish for
arbitrary `N,r,s`.  v0.12B12 is now kernel-verified: it proves symmetry and
closes strictly off-diagonal entries.  For `r < s`, the square contribution is
`-1/2` times the already verified gradient-linear square sum at `s`, while the
star interpolation contribution is `-gdStarWeightQ N s / 2`.  v0.12B13 now
handles the remaining diagonal family and complete identity assembly.

Universal checker acceptance and the arbitrary-`N` upper theorem are not
claimed until every ordered quadratic entry is closed and the complete
`QuadPolyQ` identity is assembled.
