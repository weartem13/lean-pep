# v0.12B6 arbitrary-`N` constant-coefficient reduction

## Scope

v0.12B5 kernel-verified the complete function-value coefficient channel of the
closed-form `gdUpperCertQ N` certificate.  This slice begins the constant
channel without changing certificate data or checker semantics.

The purpose is to separate structural coefficient projection from the remaining
finite rational summation.  This keeps the next proof obligation small and
fully explicit.

## Structural projection

The new module proves:

```text
pointValuePolyQ_constCoeff
gradAffineQ_constCoeff
slackPolyQ_constCoeff
interpPolySumQ_constCoeff
squarePolySumQ_constCoeff
certificateRhsPolyQ_constCoeff
upperTargetPolyQ_constCoeff
```

Thus all interpolation terms contribute zero to the constant coefficient, and
the complete certificate constant comes only from the affine-square list.

## Generated square constants

For the centered reverse-LDL factor at index `k`, Lean source proves

```text
(gdSquareFormQ N k).constCoeff
  = -1 / (2 * N - k.val + 1).
```

The one-term constant contribution is therefore

```text
gdSquareWeightQ N k * (1 / (2 * N - k.val + 1))^2.
```

The complete contribution is named `gdConstantSumQ N`.

## Reduced obligation

The main reduction theorem is

```text
gdCertificate_constCoeff_eq_target_iff (N) :
  certificateConstant = targetConstant
    <-> gdConstantSumQ N = gdBoundQ N.
```

The right-hand side is exposed as `gdConstantCoefficientIdentityQ N`.  Existing
checker-verified identities for `N = 0`, `4`, and `8` imply the corresponding
reduced scalar identities, providing regression coverage for the reduction.

## Verification boundary

This reduction is kernel-verified.  v0.12B7 supplies the separate
closed-form tail and telescoping proof of

```text
forall N, gdConstantSumQ N = gdBoundQ N.
```

Gradient-linear and ordered gradient-quadratic coefficient channels remain
separate later obligations.
