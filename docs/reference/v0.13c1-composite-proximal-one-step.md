## Actual mathematical problem

Let E be a real Hilbert space, f a differentiable convex function with a
1-Lipschitz gradient g, and h : E -> R a real-valued convex function.
The reference point x_star has the composite stationarity certificate

    -g(x_star) in partial h(x_star).

This means a GLOBAL supporting hyperplane for h. It does NOT assert either
g(x_star) = 0 or 0 in partial h(x_star). The reference is a global minimizer
of f+h, by `Proximal.composite_globalMin`.

The one-step iterate x_1 is an actual global minimizer of

    z |-> h(z) + (1/2) ||z - (x_0 - g(x_0))||^2.

Assume ||x_0-x_star||^2 <= 1. The proposed Lean theorem concludes

    (f(x_1)+h(x_1)) - (f(x_star)+h(x_star)) <= 1/4.

`upper_analytic` requires the actual analytic contract for f, convexity of h,
the stationarity certificate, proximal minimality, and the radius inequality.
It does not require a Gram datum, a residual subgradient chosen by the caller,
finite feasibility, or a pre-proved trajectory realization.

Here, as elsewhere in the project, “analytic” means the actual-gradient,
convexity and Lipschitz-gradient contract, NOT power-series real analyticity.

## Proximal optimality is proved, not postulated

`ActualFunction/Proximal.lean` defines:

* `SubgradientAt h s x`: for every y, h(x)+<s,y-x> <= h(y).
* `IsUnitProxPoint h v x`: the global minimization property of the unit proximal
  subproblem (written with an inner square, with a proved norm-square equivalent).

Under convexity of h, `isUnitProxPoint_iff_subgradient` proves

    IsUnitProxPoint h v x <-> SubgradientAt h (v-x) x.

Sufficiency follows by the exact quadratic remainder and nonnegative norm
square. Necessity considers (1-t)x+t y, combines convexity and proximal
minimality, and extracts the nonnegative linear term from

    0 <= t*a + t^2*b, for 0<t<=1, b>=0.

The scalar lemma is proved by the explicit choice t=(-a)/(b-a) when a<0,
not by an unproved differentiability or subdifferential rule.

`forwardBackwardStep_of_prox` obtains s_1=x_0-g_0-x_1 and proves both
s_1 in partial h(x_1) and x_1=x_0-g_0-s_1. Conversely the residual/update
contract implies actual proximal minimality.

## A composite compiler, not cross-component smooth interpolation

`Profiles/Composite.lean` adds parameterized value-slot/basis dimensions,
`SampleQ`, `ComponentQ`, and a two-class `FunctionClassQ`:

* `oneSmoothConvex`: value difference minus support term minus half the
  squared oracle difference;
* `convex`: value difference minus support term, with no gradient-square term.

Each component compiles ALL ordered pairs within its own sample list.
There is no pair between two different functions. Components share one Gram
basis but may have different value slots, points and oracle answers. Extra
normalization constraints and a linear objective are supplied by `ProfileQ`.

This is an initial composite function-class/compiler slice. The one-step
implicit algorithm is encoded by rational position/oracle vectors in its
profile recipe; this is NOT yet an arbitrary-horizon proximal algorithm
compiler, arbitrary class plugin system, or new external-source schema.

### Crucial application rule

The existing `GramPEP.ModelQ` is used as an explicit-constraint carrier.
Its position and gradient slot functions are identically zero, intentionally:
these fields are NOT the actual component samples. Actual positions and
oracles are represented in the component records and hence in the compiled
linear assumptions. This representation prevents pretending that all value
slots belong to one smooth function.

`GramPEP/ExplicitConstraints.lean` proves the new application rule
`checkUpperCertQ_sound_real_explicit` from the UNCHANGED checker soundness,
nonnegative explicit assumptions and dual PSD pairing. Its hypotheses are:

    checkUpperCertQ c = true
    c.interpTerms = []
    IsGramPosSemidef d.gram
    AssumptionsFeasibleR model d

The empty `interpTerms` hypothesis is essential, explicit and retained in the
generic profile wrapper, along with the exact objective equality. The old
`checkUpperCertQ` itself is NOT changed to reject nonempty lists; rather this
new application theorem cannot be invoked on such a certificate without
proving the extra equality. We do not claim the old `CoreFeasible` theorem
applies to mixed-function slots.

Actual function-class constraints are individually justified in
`ActualFunction/Composite.lean` via `SampleDenotes`, ambient Gram realization,
the old smooth interpolation theorem, and the new subgradient contract.
A pure Gram/value datum with zero dummy position/gradient fields suffices.

## Exact one-step formulation and certificate

Value-slot order (5):

    f_star, f_0, f_1, h_star, h_1

Shared Gram basis (5):

    u=x_0-x_star, g_star, g_0, g_1, s_1

Smooth samples: (0,g_star), (u,g_0), (u-g_0-s_1,g_1).
Nonsmooth samples: (0,-g_star), (u-g_0-s_1,s_1).

Constraint order (14): 9 row-major smooth pairs (*,0,1), 4 row-major convex
pairs (*,1), then 1-G_00. Self pairs are kept. The objective is
(f_1+h_1)-(f_star+h_star).

The nonzero explicit assumption multipliers are:

| Zero-based index | Meaning | Weight |
|---:|---|---:|
| 1 | smooth (*,0) | 1/2 |
| 5 | smooth (0,1) | 1/2 |
| 2 | smooth (*,1) | 1/2 |
| 10 | convex (*,1) | 1 |
| 13 | initial squared radius | 1/4 |

The exact dual factors are:

| Weight | Vector in the above basis |
|---:|---|
| 1/4 | (1,0,-1,-1,-2) |
| 1/2 | (0,1,-1/2,-1/2,0) |
| 1/8 | (0,0,1,-1,0) |

Thus `1/4 - objective` equals the five weighted assumptions plus

    (1/4)||u-g_0-g_1-2s_1||^2
  + (1/2)||g_star-(g_0+g_1)/2||^2
  + (1/8)||g_0-g_1||^2.

`upperCertQ_check` submits this coefficient identity and weighted-rank-one
factorization to the existing checker using `decide +kernel`. There is no
new PSD decision procedure, native-evaluation proof, floating-point solve or
rationalized eigenvector. The matrix is singular; its rank-three check is an
independent Python regression, not a claimed Lean rank theorem.

## Matching finite and actual lower witnesses

Finite primal: G=vv^T with

    v = (1,1,1,1,-1/2),
    values = (0,1,1/2,0,-1/4).

The old PSD and explicit-assumption primal checkers are reused, with their
existing rational-to-real bridges. This proves a candidate finite IsGreatest
at 1/4 in the PSD-plus-explicit-constraints formulation.

`primalQ_implicit_interpolation_rejected` intentionally checks that the old
all-slot smooth interpolation checker returns false on this mixed-function
datum. The old full smooth-only ExternalBundle audit is therefore NOT claimed
to support this composite instance. No schema/importer was modified.

The independent actual lower witness is

    f(x)=x,  g(x)=1,
    h(x)=max(x,0)/2-x,
    x_star=0, x_0=1, x_1=1/2.

The sum is max(x,0)/2 and is minimized at zero. At the reference,
g_star=1 and s_star=-1 cancel. At the output, s_1=-1/2; it is the residual
of the actual proximal subproblem at forward point zero. The objective gap
is exactly 1/4. Negative h_1=-1/4 is valid: h need not be bounded below by
h_star, only the composite objective has the reference minimum.

`oneDimensionalAnalyticValues` directly quantifies actual f,h,g, convexity,
composite stationarity, proximal minimality, radius and objective equality.
It contains no Gram feasibility or checker hypothesis. Its IsGreatest proof
combines the explicit actual lower witness with the certificate-based upper.
No interpolation completeness is used. The usual arbitrary-Hilbert upper and
one-dimensional actual tightness conjunction is also provided.

## Validation and limits

The new Python file contains 27 exact Fraction regressions. It parses the
source profile's vectors, sample records, bound, explicit multipliers, dual
factors and primal data, and independently expands the full coefficient
identity. The actual-data tests include affine-quadratic smooth functions
plus shifted l1 terms, dimensions 1/2/5, composite gradient cancellation and
strict radius slack. Mutations cover ordering, missing supports, reversed
pairs, extra unjustified smoothness, separate stationarity, implicit update,
wrong objectives/bounds, missing or negative factors, and exact tiny residuals.
They do not test Lean parsing/elaboration and do not replace the kernel.

Scope limitations:

* normalized L=1, radius bound 1, exactly one unit proximal-gradient step;
* real-valued convex h, not extended-real indicators or general domains;
* explicit composite stationarity certificate at the reference; no new theorem
  derives that certificate from an arbitrary global minimizer of f+h;
* assumes an actual prox minimizer, does not prove existence/select a prox map;
* no arbitrary-horizon composite profile family/rate, general step size or L,R
  theorem, new live source capture, composite external schema, stochastic PEP,
  interpolation completeness, or claimed new optimization-theory rate.

All new Lean results remain source candidates pending the local build/smoke.
