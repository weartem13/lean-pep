## Generic profile bridge

`ProfileGram` works for any `GramCompilation.PEPProfileQ N` and any real
inner-product space.  Its ambient vector family is

```text
x0 - xStar, g(points 0), ..., g(points N).
```

This family need not be linearly independent, and the Gram matrix may be
singular or zero.  The supplied normalization is an arbitrary rational
`radiusSq` with the actual assumption `||x0-xStar||^2 <= radiusSq`; it is never
silently replaced by an equality or a positive-radius assumption.

`realize_affineVecQ` identifies Gram realization of the compiled affine vector
with the preexisting generic `ParametricGDHilbert.evalVector`.  No affine or
polynomial syntax is duplicated.  `realizesProfile_iff_updates` exposes the
ambient semantic contract as the actual cumulative fixed-step equations:

```text
points i = x0 - sum_j (profile.stepCoeff i j : Real) * g(points j).
```

In the Lean statement the multiplication above is vector scalar multiplication.
`realizesActualSamples` then proves both the position and gradient fields of
the compiler-generated `ModelQ` denote the intended actual samples, including
stationarity of `xStar`.

`profileData` uses `FiniteGram.dataOfModel` unchanged.  Theorems establish
model realization, exact equality of each ordered interpolation slack, PSD,
all ordered interpolation inequalities, the radius assumption, and objective
evaluation.  `certificate_upper` consumes an accepted `GramPEP.UpperCertQ`
and an explicit equality of its objective with `compileObjectiveQ profile`.
It returns the actual value gap specified by the profile's target/reference.

The first-order entry point assumes the existing `IsOneSmoothConvexFirstOrder`.
The Hilbert-space analytic wrapper uses the existing `toFirstOrder` theorem,
not an assumed interpolation axiom.

## Actual momentum realization

`MomentumActual.iteratePair` is an actual oracle-driven recursion:

```text
x_0 = y_0 = x0
x_(k+1) = y_k - (s.step k : Real) * g(y_k)
y_(k+1) = x_(k+1) + (s.momentum k : Real) * (x_(k+1) - x_k).
```

`state` and `query` are its two projections.  The recursion is independent of
finite Gram data, polynomial identities, and certificates.  Schedules remain
arbitrary rational functions; structural correctness is not a claim that all
schedules converge.

`affineTrajectory_realization` proves the actual state AND query agree with the
B1 affine expressions at every `k <= N`.  It inducts on the actual recurrence
and reuses `stateAffineQ_succ`, `queryAffineQ_succ`, and the existing generic
affine evaluation laws.  Every actual oracle call in the step is at `y_k`.

`outputPoints` selects queries for `i < N` and the state `x_N` at `i = N`.
`outputPoints_realizesProfile` proves this is precisely `outputProfileQ N s`.
The terminal gradient is sampled for interpolation only; no update consumes it.
At `N = 0`, the only non-star sample is the initial state and its gradient.

The `IsRun` interface states the same ordinary initial/update equations for
externally defined sequences `x,y`.  `eq_of_isRun` proves their equality to the
recursive state/query pair through `N`, so callers need not adopt our concrete
recursive definitions.

## Four-step universal upper theorem

`NesterovPilotUpper` specializes the generic bridge to the UNCHANGED B1 schedule
and certificate:

```text
step(k) = 1
momentum(k) = k / (k + 3), starting at k = 0.
```

The verified theorem `upper_analytic` states, for any real Hilbert space and
`IsOneSmoothConvexAnalytic f g`, with `g(xStar)=0` and `||x0-xStar||^2 <= 1`,

```text
f(iterate g x0 4) - f(xStar) <= 1/21.
```

`upper_firstOrder` is the corresponding first-order theorem without ambient
completeness.  `upper_analytic_of_isRun` supports externally defined runs.
All three rely on B1's `pilotUpperCertQ_check` through the generic bridge;
none assumes `CoreFeasible`, `RealizesModelQ`, or an unproved trajectory
identity as an external premise.

## Validation and explicit limits

`tests/python/test_momentum_actual.py` adds 20 exact Fraction-based tests.  They execute
actual quadratic and piecewise one-sided Huber oracles, compare ambient
state/query trajectories against the coefficient compiler, build actual Gram
matrices, and test every ordered slack and the original certificate identity.
They cover dimensions 1/2/5, horizons 0..12 for structural tests, signed
schedules, zero radius, nonunit radius slack, translation, and value shifts.

Mutation checks detect using a state rather than a query as oracle input,
swapping gradient basis entries, using the unused final query as output,
forgetting centering, and claiming stationarity at a nonstationary reference.
These exact regressions do NOT execute the new Lean proofs.

B2 deliberately does not prove a new actual lower witness, an actual-function
`IsGreatest`, interpolation completeness, general `L,R` scaling of the pilot,
or an arbitrary-horizon accelerated rate.  An exact Huber execution regression
matches B1's finite primal at `1/21`, but it is NOT a Lean lower-attainment
theorem.  That remains a separate next slice.
