# v0.12B5 arbitrary-`N` function-value coefficient identity

## Scope

v0.12B4 kernel-verified the local interpolation-flow recurrences

```text
a_0 = c_0,
a_{k+1} = c_{k+1} - c_k,
a_N = 1 - c_{N-1},
```

with the zero-step endpoint handled separately.  This slice folds those
recurrences through the actual `gdStarTermsQ` and `gdChainTermsQ` lists used by
`gdUpperCertQ N`.

No certificate data or checker semantics are changed.

## Exact coefficient projection

The module first proves generic projection lemmas:

```text
slackPolyQ_valueCoeff
interpPolySumQ_valueCoeff
interpPolySumQ_append_valueCoeff
squarePolySumQ_valueCoeff
```

They establish that interpolation slacks carry only the expected
`f_i - f_j` coefficients and that affine-square terms carry no function-value
coefficients.

For the generated lists, Lean source then proves:

```text
gdStarTermsQ_valueCoeff
gdChainTermsQ_valueCoeff
gdChainSourceSumQ_eq
gdChainSourceSumQ_last
gdChainTargetSumQ_eq
gdChainTargetSumQ_zero
```

Thus the full certificate coefficient at index `r` is exactly

```text
-a_r + outgoing_r - incoming_r.
```

The v0.12B4 recurrences reduce this expression to `0` for every intermediate
index and `-1` for the final index.

## Main theorem

The universal function-value channel is exposed as:

```text
gdCertificate_valueCoefficients (N : Nat) :
  forall r : Fin (N + 1),
    (certificateRhsPolyQ (gdUpperCertQ N)).valueCoeff r =
      (upperTargetPolyQ (gdBoundQ N) (gdObjective N)).valueCoeff r
```

This closes one of the four coefficient families in
`gdCertificateIdentityQ N`.
