## Exact scope and indexing

Write T = n + 1. Every n : Nat gives a model for exactly T positive, unit-step
proximal-gradient updates. Thus compiler parameter 0 means ONE step. The run
predicate itself permits zero steps, but no zero-step objective or rate is
compiled. This avoids demanding an unavailable h-subgradient at the initial
point and avoids suggesting that a radius alone bounds a general nonsmooth
initial objective gap.

    x_(k+1) is a global minimizer of
      h(z) + (1/2) ||z - (x_k - g(x_k))||^2,  k < T.

For real-valued convex h, C1's proved proximal optimality equivalence supplies

    s_(k+1) = x_k - g(x_k) - x_(k+1) in partial h(x_(k+1)).

The compiler does not solve the implicit update and does not assert existence
of such an x_(k+1). It interprets a supplied actual run and proves its finite
constraints. `IsResidualRun.residual_eq` ensures a residual witness cannot be
chosen independently of the update.

The smooth component is normalized one-smooth convex. Composite stationarity
is still -g(x_star) in partial h(x_star), not separate stationarity of f and h.
The initial condition is ||x_0-x_star||^2 <= 1. The objective is the FINAL
composite gap (f+h)(x_T)-(f+h)(x_star), not the smooth-only gap.

## Ordering and compiler

    smooth samples:      star, x_0, ..., x_T
    nonsmooth samples:   star, x_1, ..., x_T
    value slots:         f_star, f_0, ..., f_T, h_star, h_1, ..., h_T
    Gram vector family:  x_0-x_star, g_star, g_0, ..., g_T, s_1, ..., s_T

Both finite dimensions equal 2T+3, although their type-level sums distinguish
the two value blocks from the Gram blocks. Fin.castAdd / Fin.natAdd embed the
blocks without modular wraparound. Value-block injections, disjointness and
coverage are proved. `j : Fin T` indexes s_(j+1).

The recursive symbolic position compiler implements

    X_(k+1) = X_k - G_k - S_(k+1).

Beyond its declared horizon it is frozen, purely to make the Nat-indexed
helper total. Actual realization is stated ONLY at indices <= T. Causality
proofs show g_j is absent from X_k for k <= j, and s_(j+1) is absent for k <= j.
The terminal observation g_T is therefore absent from every update.

`profileQ n` is an instance of C1's Composite.ProfileQ. It is fed to the SAME
Composite.compileModelQ. The constraint count is

    (T+2)^2 + (T+1)^2 + 1.

Order is row-major smooth pairs, row-major nonsmooth pairs, then radius.
There is no cross-component interpolation and no smooth square term for h.
The ModelQ position/gradient fields remain dummy carrier fields; actual sample
positions/oracles live in the ComponentQ records and compiled expressions.

## Actual semantics

`IsProxRun N h g x` is an ordinary local minimization contract at k < N.
`IsResidualRun` reuses C1's IsUnitForwardBackwardStep. Restriction to a prefix,
conversion in both directions (convexity for prox -> residual), and residual
uniqueness are proved.

A finite family of actual vectors supplies a Gram matrix by the unchanged
FiniteGram.gramOfVectors. The bridge establishes:

    position_realization
    smoothSamples_denote / nonsmoothSamples_denote
    radius_eval / objective_eval
    actualData_constraints
    certificate_upper / certificate_upper_of_prox / certificate_upper_analytic

`position_realization` is proved by induction from local updates, not assumed
as a premise of the final actual-function theorem. The final theorem needs an
accepted certificate for this horizon, an EMPTY c.interpTerms list, and exact
objective equality. It does not need CoreFeasible or a caller-provided Gram
realization. FiniteGram supplies PSD even when the Gram matrix is singular or
the initial radius is zero.

For c : UpperCertQ (modelQ n), the accepted-certificate theorem gives

    (f+h)(x_(n+1)) - (f+h)(x_star) <= (c.bound : Real).

There is NO unconditional bound function of arbitrary n in C2. In particular,
C2 does not claim checker acceptance of a 1/(4T) certificate, a new all-horizon
convergence rate, or all-horizon actual tightness.

## Exact C1 migration

At n=0, the following equalities are proved:

    smoothSamplesQ 0   = ProximalGradientOneStep.smoothSamplesQ
    nonsmoothSamplesQ 0 = ProximalGradientOneStep.nonsmoothSamplesQ
    radiusExprQ 0      = ProximalGradientOneStep.radiusExprQ
    objectiveQ 0       = ProximalGradientOneStep.objectiveQ
    modelQ 0           = ProximalGradientOneStep.modelQ

`oneStep_exact_certificate` transports the OLD C1 certificate through this
model equality. No dual factors, weights, or checker definitions are changed.
`oneStep_upper_analytic` exercises the NEW all-horizon actual bridge using
that transported certificate, rather than invoking the old actual upper
bound directly.

`oneDimensionalAnalyticValues_zero` proves exact equality of the new run-based
actual one-step value set and C1's point-based set. The existing actual lower
witness and IsGreatest are transported only at T=1. The new set for other
horizons is a definition, not an all-horizon tightness claim.
