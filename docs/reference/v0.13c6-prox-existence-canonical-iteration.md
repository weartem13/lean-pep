## Actual existence, not a renamed premise

`ProximalExistence.lean` uses the existing C4 predicate

    IsProxPoint L h v x

for minimization of h(x)+(L/2)||x-v||^2. L is the inverse prox step size.
The input assumptions are L>0, real-valued whole-space convex h, and finite
dimension. No initial subgradient, supporting vector, continuity premise,
lower bound on h, or composite minimizer is requested.

For each v, finite-dimensional convex continuity and compactness of the
closed unit ball give z maximizing h on that ball. Set C=h(z)-h(v)>=0.
For x!=v set r=||x-v|| and y=v-(x-v)/r. Then y is in the unit ball and

    v = x/(r+1) + r*y/(r+1).

Convexity and h(y)<=h(z) imply

    h(v)-C*||x-v|| <= h(x).

The x=v branch avoids division by zero. This argument also works in the
zero-dimensional space: no nontriviality premise is imposed.

Define Q(x)=h(x)+(L/2)||x-v||^2 and choose the radius B=2*C/L+1>0.
Whenever ||x-v||>B, the radial lower bound and positive quadratic term give
Q(x)>=h(v)=Q(v). Q has a minimum on the compact closed ball of radius B;
this is therefore a global minimum. The original C5 uniqueness theorem gives
`existsUnique_isProxPoint` for the original predicate. h itself may be
unbounded below, for example affine h(x)=-x.

Library interfaces were checked in the pinned mathlib v4.31.0 sources:
`ConvexOn.continuousOn`, `FiniteDimensional.proper_real`,
`IsCompact.exists_isMaxOn`, `IsCompact.exists_isMinOn`, and
`Metric.mem_closedBall_iff_norm`. This source inspection is not elaboration.

## A proved selector and a coherent run

`ProximalIteration.lean` introduces the proposition

    HasProx L h := forall v, exists x, IsProxPoint L h v x.

This is a hypothesis in generic lemmas, not an axiom or a new typeclass
instance. `hasProx_of_finiteDimensional` proves it from the assumptions above.
`proxMap hp v` selects the witness of hp(v); there is no fallback branch.
`proxMap_spec` retains the actual global minimization property. C5 uniqueness
proves equality with any supplied solution and with any exact selector.

The actual recursion is

    x_0 = x0
    x_(k+1) = proxMap hp (x_k - (1/L)*g(x_k)).

The map is chosen independently of the horizon. `exists_all_horizons` thus
constructs one infinite sequence, not unrelated solutions for each prefix.
`iterate_isSmoothProxRun` proves the old physical run predicate for every N.
`run_eq_iterate` identifies any supplied same-initial-value run with this
sequence for k<=N. `isSmoothProxRun_iff_eq_iterate` includes the converse.
No property beyond the supplied horizon is inferred. These structural facts
do not require smoothness of g or completeness; uniqueness requires convex h
and positive L. `finiteDimensionalIterate` discharges HasProx internally.

## Unchanged rate and unchanged actual witness

`ProximalGradientCanonical.lean` calls C5's original minimizer-facing wrappers.
The generic certificate boundary keeps acceptance, empty implicit interpTerms,
and exact objective equality. Specific rate theorems use the old accepted
certificate through C5 and never rewrite a multiplier, factor, or model.

`upper_analytic_steps_finiteDimensional` takes T>0, L>0, R>=0, the old actual
smooth-convex condition for f/g, convex h, an ordinary minimizer of f+h, and
||x0-xStar||^2<=R^2. It proves the candidate bound for finiteDimensionalIterate:

    (f+h)(x_T)-(f+h)(xStar) <= L*R^2/(4*T).

There is no caller-supplied trajectory, HasProx proof, stationarity vector,
continuity assumption, Gram datum or checker acceptance. The exact-radius
corollary sets R=||x0-xStar||. `iterate_at_minimizer` retains nonzero component
cancellation and covers the zero-radius case without inverting the radius.

`iterate_witness` identifies the chosen run with the old scaled witness on
k<=n+1. The witness's affine formula is not continued beyond that proved
prefix. In the actual infinite canonical run its later behavior can differ.

`oneDimensionalValues n L R` quantifies actual f,h,g,xStar,x0 and a proof of
total prox solvability, then uses the selected recursion instead of a free
sequence. That existential proof is always supplied by finite-dimensional
existence for convex h and positive L. `oneDimensionalValues_eq_minimizerValues`
proves equality with the entire old C5 supplied-run set, not just equality of
bounds. It requires L>0, but places no extra sign condition on R. `tight_all`
then transfers the established IsGreatest result for R>=0. The compiler
parameter remains n+1 steps, while the upper interface also accepts T directly.
