## Actual unit-step recursion

The actual iterate is defined recursively by

```text
x_0 = x0
x_(k+1) = x_k - g(x_k).
```

The public Lean definition is:

```lean
unitGDIterate (g : E → E) (x0 : E) : ℕ → E
```

The candidate also exposes the sampled gradient and centered function value
arrays:

```lean
sampledGradient N g x0 k = g (unitGDIterate g x0 k.val)
sampledValue N f g xStar x0 k =
  f (unitGDIterate g x0 k.val) - f xStar
```

## Candidate upper theorem

The first-order theorem is:

```lean
IsOneSmoothConvexFirstOrder.parametricGD_upper_exact_radius
```

with conclusion

```text
f (unitGDIterate g x0 N) - f xStar
  <= (gdBoundQ N : Real) * ||x0 - xStar||^2.
```

Since

```text
gdBoundQ N = 1 / (4N + 2),
```

this is the normalized arbitrary-length actual-function rate.  A unit-radius
presentation is also provided:

```lean
IsOneSmoothConvexFirstOrder.parametricGD_upper_unit_radius
```

The analysis-facing structure receives matching corollaries:

```lean

IsOneSmoothConvexAnalytic.parametricGD_upper_unit_radius
```

## Boundary

C2 is still normalized to a `1`-Lipschitz gradient and unit step size.  The
v0.12C3 source candidate combines this theorem with the existing general
smoothness normalization to obtain

```text
f(x_N) - f(xStar) <= L * R^2 / (4N + 2)
```

for step size `1/L`.  A matching actual lower witness or interpolation
completeness remains necessary before claiming a tight actual-function
worst-case theorem.
