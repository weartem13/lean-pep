# v0.12B4 exact interpolation-flow telescoping

## Scope

v0.12B3 kernel-verified all sign obligations for the closed-form certificate
and reduced arbitrary-`N` checker acceptance to the single proposition
`gdCertificateIdentityQ N`.

This slice isolates the rational flow identities responsible for cancelling
all intermediate function-value coefficients.  It does not change the
certificate generator or the generic checker.

## Closed-form flow

For positive `N`, the consecutive interpolation multiplier is

```text
c_k = (k + 1) / (2N - k),  k < N.
```

The generated star-to-iterate weights satisfy:

```text
a_0 = c_0,
a_{k+1} = c_{k+1} - c_k       when k + 1 < N,
a_N = 1 - c_{N-1}.
```

The zero-step case has the unique star weight `a_0 = 1`.

The corresponding Lean declarations are:

```text
gdStarWeightQ_zero_zero
gdStarWeightQ_zero_eq_chainWeightQ_zero
gdStarWeightQ_succ_eq_chainWeightQ_sub
gdStarWeightQ_last_eq_one_sub_chainWeightQ_last
```

The auxiliary identity

```text
gdBoundQ N = (1/2) * gdCenterQ N
```

is also proved for use in the constant and linear coefficient calculations.

## Verification boundary

These recurrences are kernel-verified.  They are the algebraic inputs to the
function-value telescope, but do not by themselves prove the complete
`QuadPolyQ.valueCoeff` equality or `gdCertificateIdentityQ N`.

v0.12B5 folds them through `gdStarTermsQ` and `gdChainTermsQ` and targets the
complete function-value coefficient channel.  Constant, gradient-linear, and
gradient-quadratic coefficients remain separate obligations before universal
checker acceptance.
