## Purpose of D4

D4 transports the explicit normalized witness to a positive smoothness
constant `L : ℝ≥0` and a nonnegative radius `R : ℝ`.  It does not modify the
upper certificate, finite-PEP semantics, or the normalized witness.

The new module is:

```text
LeanPEP/ActualFunction/HuberWitnessScaling.lean
```

## Scaled function and gradient

D4 defines

```text
scaledThreshold N R = R * threshold N,

scaledWitnessFunction N L R x
  = L * huberFunction (scaledThreshold N R) x,

scaledWitnessGradient N L R x
  = L * huberGradient (scaledThreshold N R) x.
```

For `R >= 0`, the elementary scale identities are

```text
huberGradient (R*a) (R*x) = R * huberGradient a x,
huberFunction (R*a) (R*x) = R^2 * huberFunction a x.
```

Consequently, at radius-scaled normalized points,

```text
scaledWitnessFunction ... (R*x)
  = L * R^2 * witnessFunction N x,

scaledWitnessGradient ... (R*x)
  = L * R * witnessGradient N x.
```

## Analytic class membership

D4 proves directly that

```lean
scaledWitness_analytic (N : Nat) (L : NNReal) (R : Real) :
  IsSmoothConvexAnalytic L
    (scaledWitnessFunction N L R)
    (scaledWitnessGradient N L R)
```

The proof uses:

- constant multiplication of the D3 derivative theorem;
- monotonicity of the scaled clipped gradient and the derivative convexity
  criterion; and
- a direct distance proof that multiplying a `1`-Lipschitz scalar field by
  `L` gives an `L`-Lipschitz field.

No positivity hypothesis on `R` is needed for analytic membership itself.
Nonnegative `R` is used for stationarity/global-minimum and trajectory scaling.

## Step-size-`1/L` trajectory

The scaled closed-form points are

```text
scaledWitnessPoint N R k = R * witnessPoint N k.
```

For `L > 0` and `R >= 0`, D4 proves

```lean
smoothGDIterate_eq_scaledWitnessPoint
```

for every index through `N + 1`.  The cancellation

```text
(1/L) * (L * R * threshold N) = R * threshold N
```

is checked exactly in `ℝ`; no floating-point computation is involved.

## Exact attainment

The general bound is

```lean
generalBound N L R = L * R^2 * gdBoundQ N.
```

D4 proves

```lean
scaledWitness_smoothGD_attains_bound
scaledWitness_smoothGD_attains_closed_form
```

with the closed form

```text
L * R^2 / (4N + 2).
```

The theorem

```lean
general_analytic_lower_witness
```

packages analytic membership, stationarity at zero, global minimality, exact
initial radius, and exact attainment.

## Exact one-dimensional worst case

D4 defines

```lean
oneDimensionalAnalyticGDValues N L R : Set Real
```

as the values attained by one-dimensional analytic `L`-smooth convex
instances with stationary comparison point and squared initial radius at most
`R^2`.

It then proves the candidate theorem

```lean
oneDimensional_analytic_tight ... :
  IsGreatest
    (oneDimensionalAnalyticGDValues N L R)
    (generalBound N L R)
```

by combining:

1. the scaled Huber witness for membership and attainment; and
2. the kernel-verified v0.12C3 universal upper theorem for maximality.

Finally,

```lean
analytic_upper_and_oneDimensional_tight
```

packages the dimension-independent upper bound for an arbitrary real Hilbert
space together with exact one-dimensional attainment.

## Boundary

D4 does not prove interpolation completeness for arbitrary finite feasible
data, does not add a new numerical or PEPit artifact, and does not prove an
oracle-complexity lower bound.  The tight theorem comes from one explicit
actual analytic witness plus the already verified universal upper theorem.
