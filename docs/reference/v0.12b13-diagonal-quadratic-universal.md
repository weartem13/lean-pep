## Diagonal interpolation contribution

For one star-to-iterate slack, the diagonal coefficient is `-1/2` at the
iterate's own sampled-gradient index and zero elsewhere.  A consecutive
iterate slack contributes `-1/2` at each of its two incident gradient indices.
Consequently,

```text
gdQuadraticInterpSumQ N r r
  = -(1/2) *
      (gdStarWeightQ N r
       + gdChainSourceSumQ N r
       + gdChainTargetSumQ N r).
```

The already verified function-value flow identity implies that this equals

```text
-gdChainWeightQ N r
```

when `r < N`, and equals `-1/2` at the final index.

## Diagonal square contribution

The generated square factor at index `k` contributes to diagonal `(r,r)` as
follows:

```text
k = r : gdSquareWeightQ N r
r < k : gdConstantContributionQ N k
k < r : 0.
```

Therefore

```text
gdQuadraticSquareSumQ N r r
  = gdSquareWeightQ N r
      + gdGradientConstantSuffixQ N r.
```

For nonfinal `r`, the B10 suffix theorem replaces the strict suffix by the next
constant tail.  A local exact rational identity then proves

```text
gdSquareWeightQ N r + gdConstantTailQ N (r + 1)
  = gdChainWeightQ N r.
```

At the final index, the suffix is empty and the final square weight is `1/2`.
Thus the square diagonal cancels the interpolation diagonal at every index.

## Complete polynomial identity and checker

The candidate then assembles the already verified coefficient families:

```text
gdCertificate_constCoeff
gdCertificate_gradCoeff
gdCertificate_valueCoeff
gdCertificate_quadCoeff
```

using `QuadPolyQ.ext`.  The resulting public theorems are:

```text
gdCertificateIdentityQ_all
gdUpperCertQ_check_all
gd_upper_all.
```

`gd_upper_all` states that every feasible normalized finite GD datum of
trajectory length `N` satisfies

```text
d.value (gdObjective N) <= gdBoundQ N
```

with `gdBoundQ N = 1 / (4 * N + 2)`.

## Mathematical boundary

This is an arbitrary-length **finite PEP upper theorem**.  It is not by itself
an arbitrary-length theorem for actual smooth convex functions.  That requires
an arbitrary-trajectory actual-function-to-finite-PEP soundness bridge and then
general `L,R` scaling.  A matching actual lower witness or interpolation
completeness is still required before claiming a tight actual-function
worst-case value.
