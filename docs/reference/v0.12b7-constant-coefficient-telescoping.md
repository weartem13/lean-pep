# v0.12B7 arbitrary-`N` constant-coefficient telescope

## Scope

v0.12B6 kernel-verified the structural reduction of the generated certificate
constant coefficient to the explicit scalar sum `gdConstantSumQ N`.  This
slice proves that finite rational sum for every trajectory length without
changing the certificate, checker, or finite-GD semantics.

## Tail potential

The proof defines

```text
gdConstantTailQ N k
  = (2N - 2k + 1) / (2 (2N - k + 1)^2).
```

For every nonfinal `k < N`, the generated square contribution satisfies

```text
gdConstantContributionQ N k
  = gdConstantTailQ N k - gdConstantTailQ N (k + 1).
```

The final contribution satisfies

```text
gdConstantContributionQ N N = gdConstantTailQ N N.
```

Thus all intermediate tails cancel.

## Closed constant channel

The initial tail is proved equal to the generated bound:

```text
gdConstantTailQ N 0 = gdBoundQ N = 1 / (4N + 2).
```

Consequently:

```text
gdConstantCoefficientIdentityQ_all (N) :
  gdConstantSumQ N = gdBoundQ N
```

and the certificate/target constant coefficients agree for every `N`.

## Verification status and boundary

This telescope is kernel-verified in the Lean 4 / mathlib v4.31.0 build that
completed 3204 jobs and passed `tests/lean/smoke/V12B7SmokeTest.lean`.

After this slice, the arbitrary-`N` polynomial identity has two remaining
coefficient families:

1. gradient-linear coefficients;
2. ordered gradient-quadratic coefficients.

v0.12B8 isolates the first family as a pointwise explicit finite rational sum.
Checker acceptance for every `N` is not claimed until both families are closed
and the complete `QuadPolyQ` structures are proved equal.
