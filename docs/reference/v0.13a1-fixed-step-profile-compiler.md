# v0.13A1: exact fixed-step algorithm profile/compiler

## Status

Kernel verified with Lean 4.31.0.  The local aggregate build completed all 3220
jobs, and `tests/lean/smoke/V13A1SmokeTest.lean` checked the public profile/compiler theorem
surface, the GD migration equalities, and generated-certificate acceptance.

## Mathematical object

A profile stores exact rational cumulative coefficients `h[i,j]` for

```text
x_i = x_0 - sum_j h[i,j] g_j.
```

It includes a proof of causality:

```text
i <= j  ->  h[i,j] = 0.
```

Thus `x_i` cannot depend on the current or a future oracle answer.  The first
slice keeps the normalized conventions `x_star = 0` and `x_0 = 1` used by the
arbitrary-length v0.12 certificate.

## Compiler and checker

`LeanPEP.Profiles.FixedStepFirstOrder` compiles a profile into the existing
exact syntax:

- `GradAffineQ` for positions;
- `QuadPolyQ` for ordered smooth-convex interpolation constraints;
- the existing `UpperCertQ` term lists and affine squares;
- the existing coefficient equality decision procedure `checkPolyEqQ`.

The module proves proposition-level checker equivalence and real scalar
soundness.  No floating-point arithmetic, external solver output, or new
polynomial representation enters the trusted path.

## Gradient-descent migration

`LeanPEP.Profiles.GradientDescent` defines

```text
h[i,j] = 1  if j < i,
         0  otherwise.
```

For every horizon `N`, the following objects are proved exactly equal to the
legacy v0.12 objects:

1. cumulative gradient affine forms and `GradAffineQ.prefixAffine`;
2. compiled positions and `xAffineQ`;
3. compiled interpolation polynomials and `slackPolyQ`;
4. complete certificate right-hand sides;
5. profile-checker and legacy-checker Boolean results.

It follows that the unchanged closed-form certificate `gdUpperCertQ N` is
accepted by the profile checker for every `N`, and the normalized finite-GD
upper theorem can be derived through the new profile path.

## Deliberate boundary

This is the algorithm-profile layer only.  It does not yet provide:

- a generic function-class profile;
- normalization or objective profiles;
- a compiler to the general Gram `ModelQ` basis;
- Hilbert-space soundness for arbitrary profiles;
- Nesterov/OGM or proximal profiles.

The next mathematical slice should extract normalization/objective compilation
and then compile this profile to the general Gram model before adding the
Nesterov/OGM pilot.
