# v0.12B9 gradient-factor support and suffix reduction

Status: kernel-verified with Lean 4 / mathlib v4.31.0.

## Scope

v0.12B8 is kernel-verified: for every trajectory length `N`, the generated
certificate's gradient-linear coefficient at sampled index `r` is exactly

```text
gdStarWeightQ N r + gdGradientSquareSumQ N r.
```

This slice exposes the internal support pattern of every generated reverse-LDL
square factor.  It does not change certificate data, interpolation weights,
square weights, affine factors, the checker, or finite-GD semantics.

## Prefix coefficients

The symbolic prefix

```text
GradAffineQ.prefixAffine k
```

contains sampled gradient `g_r` exactly when `r < k`.  The module proves

```text
(prefixAffine k hk).gradCoeff r = if r.val < k then 1 else 0.
```

Centering the prefix changes only its affine constant.

## Generated square-factor support

For the generated factor `gdSquareFormQ N k`, the coefficient at sampled
index `r` is

```text
1                              if r = k
1 / (2 * N - k + 1)           if r < k
0                              if k < r.
```

The corresponding weighted square contribution therefore has the exact
pointwise form:

```text
diagonal contribution         if k = r
-2 * constantContribution k   if r < k
0                              if k < r.
```

Here `constantContribution k` is the square constant contribution already used
and universally telescoped in v0.12B7.

## Strict suffix reduction

The slice defines

```text
gdGradientConstantSuffixQ N r
  = sum over k with r < k of gdConstantContributionQ N k.
```

It then proves

```text
gdGradientSquareSumQ N r
  = gdGradientSquareContributionQ N r r
      - 2 * gdGradientConstantSuffixQ N r.
```

Thus the remaining gradient-linear family is equivalent to

```text
gdStarWeightQ N r
  + gdGradientSquareContributionQ N r r
  - 2 * gdGradientConstantSuffixQ N r
  = 0.
```

At the final index the suffix is empty, and the final star weight cancels the
final diagonal contribution exactly.

## Verified boundary and next work

The triangular support, diagonal-minus-suffix decomposition, and final-index
cancellation are kernel-verified.  v0.12B10 builds on this result by proving,
for every nonfinal index, that

```text
gdGradientConstantSuffixQ N r = gdConstantTailQ N (r.val + 1).
```

It then closes all sampled-gradient-linear coefficients for arbitrary `N`.
Ordered sampled-gradient-quadratic coefficients remain the final polynomial
channel, so universal checker acceptance is not yet claimed here.
