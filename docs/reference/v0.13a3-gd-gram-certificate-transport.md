## Scalar-to-Gram homogenization

The scalar polynomial syntax has variables

```text
g_0, ..., g_N, f_0, ..., f_N
```

and treats `x_star = 0`, `f_star = 0`, and `x_0 = 1` as normalized constants.
The compiled Gram basis and point order are

```text
basis:  x_0 - x_star, g_0, ..., g_N
points: x_star, x_0, ..., x_N.
```

`homogenizeQuadPolyQ` maps a scalar polynomial

```text
c + sum_i a_i g_i + sum_i b_i f_i + sum_ij Q_ij g_i g_j
```

to a general Gram linear expression as follows:

1. `c` becomes the coefficient of
   `G[x_0-x_star, x_0-x_star]`;
2. each linear gradient coefficient `a_i` is split equally between the two
   symmetric Gram entries involving `x_0-x_star` and `g_i`;
3. `Q_ij` becomes the `(g_i,g_j)` Gram coefficient; and
4. the scalar value combination becomes
   `sum_i b_i (f_i - f_star)`.

The module proves exact preservation of zero, addition, negation, subtraction,
rational scaling, value variables, affine products, and affine squares.
It then proves, for every ordered source pair,

```text
homogenizeQuadPolyQ (slackPolyQ i j)
  = interpolationExprQ (unitGDModelQ N) (pointIndex i) (pointIndex j).
```

Thus the bridge audits the already-declared point and basis order rather than
assuming that the scalar and Gram formulations happen to align.

## Interpolation and dual-factor transport

Every scalar interpolation term keeps its exact rational weight and maps its
source points through `pointIndex`.

Every scalar square term

```text
weight * (form)^2
```

becomes the exact Gram rank-one factor

```text
{ weight := weight, vector := affineVecQ form }.
```

The dual matrix is reconstructed by the existing `factorGramQ`; the submitted
`PSDFactorCertQ` contains the same factor list.  Consequently its factorization
identity is by construction, while nonnegativity follows from the existing
arbitrary-`N` scalar square-weight theorem.

The bridge proves that the complete scalar interpolation sum and square sum
homogenize respectively to

```text
interpExprSumQ (unitGDModelQ N) ...
gramPairing (factorGramQ transportedFactors).
```

## Radius dehomogenization

The scalar certificate identity proves a homogeneous target

```text
gdBoundQ N * ||x_0 - x_star||^2_G - (f_N - f_star).
```

The general normalized PEP target is

```text
gdBoundQ N - (f_N - f_star).
```

The difference is exactly supplied by the compiled assumption

```text
1 - ||x_0 - x_star||^2_G >= 0
```

with multiplier `gdBoundQ N`.  The module proves the coefficient identity
rather than relying on real evaluation or a normalization equality.

## Arbitrary-horizon result

The transported certificate is

```text
gdGramUpperCertQ N : GramPEP.UpperCertQ (unitGDModelQ N).
```

For every natural `N`, the module proves:

```text
gdGramUpperCertQ_identity_all
gdGramUpperCertQ_valid_all
gdGramUpperCertQ_check_all
gdGram_upper_all.
```

The last theorem states that every real datum realizing the compiler-generated
GD model, satisfying general Gram core feasibility, and satisfying its compiled
unit-radius assumption obeys

```text
(unitGDObjectiveQ N).evalR d <= gdBoundQ N.
```

This is the arbitrary-horizon finite Gram-PEP upper theorem.  The previously
verified actual-function Hilbert-space theorem remains unchanged.
