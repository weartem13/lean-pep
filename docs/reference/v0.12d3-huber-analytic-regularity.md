## Purpose of D3

D3 proves that the same function/gradient pair belongs to the standard
analysis-facing class:

```lean
IsOneSmoothConvexAnalytic
  (huberFunction a)
  (huberGradient a)
```

No trajectory definition, certificate, checker, or attainment formula is
changed.

The new module is:

```text
LeanPEP/ActualFunction/HuberWitnessAnalytic.lean
```

## Derivative on the two branches

For the quadratic branch,

```text
x ↦ x^2 / 2,
```

D3 proves derivative `x`.  For the affine branch,

```text
x ↦ a*x - a^2/2,
```

it proves derivative `a`.

Away from the join, the Huber function agrees with the corresponding branch in
a neighborhood.  At `x = a`, the proof uses `HasDerivWithinAt` on `Iic a` and
`Ici a`; both one-sided restrictions have derivative `a`, and their union is
`univ`.  The result is:

```lean
huberFunction_hasDerivAt (a x : Real) :
  HasDerivAt (huberFunction a) (huberGradient a x) x
```

and therefore:

```lean
deriv_huberFunction
huberFunction_differentiable
huberFunction_hasGradientAt
```

## Convexity

The clipped field

```text
huberGradient a x = min x a
```

is monotone.  Combined with differentiability and the exact derivative formula,
mathlib's derivative criterion yields:

```lean
huberFunction_convexOn (a : Real) :
  ConvexOn Real Set.univ (huberFunction a)
```

This is an independent analysis-facing convexity proof.  The D1 first-order
lower model remains unchanged and continues to provide a separate exact
contract.

## Lipschitz gradient

D3 reuses mathlib's nonexpansiveness theorem for `min` with a constant to prove:

```lean
huberGradient_lipschitz (a : Real) :
  LipschitzWith 1 (huberGradient a)
```

No coordinate approximation or finite sampling is involved.

## Analytic class membership

The three fields are assembled as:

```lean

  IsOneSmoothConvexAnalytic
    (huberFunction a)
    (huberGradient a)
```

and instantiated at the certificate-centered threshold:

```lean

  IsOneSmoothConvexAnalytic
    (witnessFunction N)
    (witnessGradient N)
```

The theorem


packages analytic membership, stationarity, global minimality, unit initial
radius, and the already verified D2 attainment of `gdBoundQ N`.

## Boundary

D3 does not yet prove:

- a lower witness for arbitrary positive `L` and external radius `R`;
- equality of the general `L,R` worst-case value with `L*R^2/(4N+2)`;
- interpolation completeness for arbitrary finite feasible data; or
- any oracle-complexity lower bound.

The next slice, v0.12D4, transports this explicit analytic witness to general
positive `L` and nonnegative `R`, while keeping the verified upper theorem and
normalized attainment unchanged.
