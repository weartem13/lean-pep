# v0.13A2: fixed-step profiles compiled to general Gram PEPs

## Status

Kernel verified with Lean 4.31.0.  The local aggregate build completed all
3222 jobs, and `tests/lean/smoke/V13A2SmokeTest.lean` checked the public point/basis ordering,
model compiler, one-step model equivalence, exact certificate transport, and
real upper-bound theorem surface.

## Composed profile

The first composed PEP profile has three exact components:

```text
PEPProfileQ
  algorithm      : FixedStepFirstOrder.ProfileQ N
  normalization  : NormalizationProfileQ
  objective      : ObjectiveProfileQ N
```

The function class and oracle remain the existing normalized one-smooth convex
gradient-interpolation semantics.  This slice does not yet abstract those two
components.

The normalization component stores an exact rational squared-radius bound and
compiles to

```text
radiusSq - ||x_0 - x_star||^2_G >= 0.
```

The objective component stores a target point and reference point and compiles
to the exact function-value gap

```text
f(target) - f(reference).
```

## Deterministic point and Gram-basis order

For horizon `N`, both the point array and Gram basis have size `N + 2`:

```text
point order:  x_star, x_0, ..., x_N
basis order:  x_0 - x_star, g_0, ..., g_N
```

`pointIndex` and `pointAtIndex` are proved mutually inverse.  The scalar affine
position language from v0.13A1 is homogenized into the Gram basis by mapping
its old constant coefficient to the coefficient of `x_0 - x_star` and its
sampled-gradient coefficients to the remaining basis coordinates.

The compiler proves that:

1. reading a compiled position or gradient through `pointIndex` recovers the
   source compiler exactly;
2. every iterate has coefficient one on the initial-displacement basis vector;
3. the coefficient of a current or future gradient basis vector is zero, so
   causality is preserved after Gram compilation;
4. the compiled objective evaluates to the declared function-value gap; and
5. the compiled radius expression evaluates to the declared radius slack for
   every symmetric Gram matrix.

## Gradient-descent migration

The normalized unit-step GD profile is composed with unit radius and final gap.
For arbitrary `N`, the generated positions are exactly the homogenized v0.12
scalar positions and their gradient coefficients are

```text
-1  when j < i,
 0  otherwise.
```

At `N = 1`, exact Boolean coefficient checks and proposition-level soundness
prove that the compiler output equals the established one-step Gram model in
all fields:

```text
unitGDModelQ 1 = oneStepModelQ
unitGDObjectiveQ 1 = oneStepObjectiveQ.
```

Consequently every ordered interpolation expression is unchanged.  The
existing general Gram upper checker has an accepted exact certificate for the
compiler-generated model with bound `1/6`, and the existing real one-step upper
theorem is transported to the generated model without modifying any checker.

## Trusted-core impact

No existing trusted component is changed.  In particular, this slice does not
modify:

- `GramPEP.Core`;
- `ModelQ` or `LinearExprQ`;
- the exact primal or upper-certificate checker;
- either PSD-factor checker;
- external schemas, importers, adapters, or generated artifacts; or
- the arbitrary-`N` scalar GD certificate.

The new compiler only constructs inputs to the existing Gram layer and proves
that its first migrated instance agrees with an already verified formulation.

## Deliberate boundary and next slice

This slice itself stops before translating the arbitrary-`N` scalar SOS
certificate into a general Gram dual certificate.  v0.13A3 adds precisely that
bridge:

```text
scalar interpolation multipliers
  -> Gram interpolation terms
scalar affine squares
  -> rational rank-one dual factors
scalar bound/objective identity
  -> Gram identity plus the radius assumption.
```

The Nesterov/OGM profile pilot should follow after the A3 bridge is kernel
verified, so the first profile migration closes formulation and certificate
transport before a second trajectory family is introduced.
