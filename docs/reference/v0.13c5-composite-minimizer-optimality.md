## The remaining theorem-level premise

C4 used the explicit supporting vector condition

    SubgradientAt h (-g xStar) xStar.

C5 proves this is equivalent, under the existing smooth-convex first-order
contract for f/g and convexity of real-valued h, to the ordinary condition

    for every y, f(xStar)+h(xStar) <= f(y)+h(y).

There is no requirement that either component be individually minimized at
xStar or that g(xStar)=0. This changes the user-facing hypotheses, not the
numerical rate or the underlying mathematical class. The actual value sets
with the two reference-point descriptions are proved equal.

## Reuse and proof

`CompositeOptimality.lean` first extends the original physical prox predicate:
for L>0 and convex h,

    IsProxPoint L h v x <-> SubgradientAt h (L*(v-x)) x.

Its necessity proof uses the C4 normalization with center zero and radius one,
then C1's already verified unit proximal optimality theorem. It clears a
positive scalar denominator and restores the supporting vector L*(v-x).
The sufficient direction is the unchanged C4 theorem. Uniqueness of supplied
prox minimizers follows from the existing strict quadratic remainder lemma.
These are conditional results about supplied minimizers; no arbitrary prox
existence theorem, minimizer selection, or new optimization operator is added.

For a vector a and any K>0, the quadratic support condition

    h(x) <= h(y) + <a,y-x> + K/2*||y-x||^2   for every y

produces an actual fixed point of the h-prox problem at input x-a/K. The exact
quadratic identity is

    K/2*(||y-v||^2-||x-v||^2) = <a,y-x> + K/2*||y-x||^2,
    v=x-a/K.

Proximal necessity then removes the quadratic term and yields -a in partial h(x).
To obtain the quadratic support premise from global minimality of f+h, combine
minimality with f's quadratic upper model at x. Necessity requires only that
one-point upper model, not a lower model or a globally specified gradient field.
Use K=L+1 as an auxiliary positive majorizing coefficient. This allows the
stationarity characterization to include L=0 without taking its inverse.
The coefficient K is internal to this argument and never changes a physical
run's step size 1/L. The reverse implication uses the two global linear
support inequalities; their nonzero component vectors cancel exactly.

No subdifferential sum-rule theorem, limiting oracle, interpolation completeness,
finite-dimensionality, or completeness of the ambient space is needed for the
first-order optimality lemmas. Convexity of h and the smooth upper model must
not be omitted. Counterexample regressions illustrate both boundaries.

## Same exact physical rate, stated at a minimizer

`ProximalGradientMinimizer.lean` extracts the supporting vector and calls C4's
unchanged generic certificate/upper interfaces. The generic wrapper preserves
all three certificate guards: acceptance, empty implicit interpTerms, and
objective equality. The final rate wrappers discharge these through C4 and C3B.
For an actual run with positive T, L>0, R>=0 and initial squared radius <=R^2,

    (f+h)(x_T)-(f+h)(xStar) <= L*R^2/(4*T).

The new `upper_analytic_steps_of_minimizer` takes only the existing function
assumptions, an ordinary global minimizer, physical run and radius condition.
There is no caller-supplied subgradient or Gram/checker premise. First-order,
exact-distance, and stationary-run variants are included.

`oneDimensionalMinimizerValues n L R` retains n+1 as the step count and is
proved equal to C4's `oneDimensionalAnalyticValues n L R`. Set equality itself
holds for every nonnegative L and every real R; numerical tightness is still
only stated for L>0, R>=0. The explicit C4 witness is also inserted directly
with its already verified global-minimum theorem, actual run and attainment.
The witness definitions, components and trajectory are not changed.

`minimizer_tight_all` transfers the existing IsGreatest theorem to the natural
minimizer-based set. The Hilbert upper/one-dimensional tightness pair does not
pretend to define a single cross-universe supremum.
