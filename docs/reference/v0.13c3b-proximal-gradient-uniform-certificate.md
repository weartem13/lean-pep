## 4. Function-value flow and its boundaries

Let

    q_i = i/(2T-i),  0 <= i <= T.

Then q_0=0, q_T=1, the nonsmooth star multiplier at x_(i+1) is q_(i+1)-q_i,
and the nonsmooth chain multiplier is the appropriate interior q.

The smooth cumulative flux is

    p_i = i/(2T-i+1),  0 <= i <= T,
    p_(T+1) = 1.

The terminal value 1 is explicit, not the rational formula evaluated outside
its intended interval. Its differences are the old smooth star weights,
and its interior values are the old smooth chain weights.

`weighted_flux_sum` is discrete integration by parts in ANY rational module.
Its endpoint hypotheses are included in the statement. The two specialized
flow lemmas therefore apply to full coefficient vectors, not just scalar
function samples. The smooth and nonsmooth value terms reduce to their
respective star and terminal slots.

The nonsmooth samples still start at x_1; there is no fabricated subgradient
at x_0. At n=0, the nonsmooth chain sum is empty and the same proof applies.

## 5. The local square identity

For each edge i<T, let A_i,r_i,c_i,e_i,beta_i be the UNCHANGED C3A formulas.
Define the new proof potential

    rho_i = (T-i)/(2T-i)^2.

Its boundaries are rho_0=1/(4T) and rho_T=0. Every denominator 2T-i used at
a node is positive, as is 2T-i-1 on an edge. In particular, the proof never
divides by T-i, which would vanish at the terminal node.

`local_weight_identities` proves these six rational coefficient relations:

    A_i-q_i = rho_i,
    A_i*r_i^2-q_(i+1) = -rho_(i+1),
    2*A_i*r_i = q_i+q_(i+1),
    2*A_i*c_i = beta_i,
    2*A_i*r_i*c_i = q_(i+1),
    A_i*c_i^2+e_i = beta_i/2.

For arbitrary rational X,Y,G,H and S=X-Y-G, they imply

    A_i (X-r_i Y-c_i(G-H))^2 + e_i(G-H)^2
      + beta_i ((G-H)X - (G-H)^2/2)
      + q_(i+1) S Y - q_i S X
    = rho_i X^2 - rho_(i+1) Y^2
      + q_i G X - q_(i+1) H Y.

The proof uses an explicit linear combination of the six coefficient
relations. No nonlinear solver or approximate equality is involved.

`local_gram_identity` polarizes this equality to prove EVERY Gram coefficient,
including off-diagonals. It uses the sum of two arbitrary coordinate values
and subtracts their separate diagonal identities, then divides by two.
Thus it proves an equality of full coefficient objects for arbitrary rational
coefficient vectors, not only an equality on the attaining witness, diagonal
matrices or PSD inputs.

## 6. Sum the local identities and recover the old checker target

For the original compiler positions X_i and smooth gradient vectors G_i,
its existing update theorem gives

    S_(i+1) = X_i-X_(i+1)-G_i.

After the two component flow lemmas, the original certificate's quadratic
part is precisely the sum of the local identities. Define the coefficient
potential

    P_i = rho_i ||X_i||_G^2 + q_i <G_i,X_i>_G.

Each edge contributes P_i-P_(i+1). Finite telescoping gives

    P_0-P_T = (1/(4T))||X_0||_G^2 - <G_T,X_T>_G.

The terminal pairing cancels the remaining smooth endpoint term. The radius
assumption supplies

    (1/(4T))(1-||X_0||_G^2),

so its sum with the initial potential is exactly the constant 1/(4T).
The radius inequality has NOT been replaced with an equality.

`certificateIdentityQ_all` then recovers

    certificateRhsExprQ (upperCertQ n)
      = upperTargetExprQ (boundQ n) (objectiveQ n).

The existing `upperCertQ_check_iff_identity`, already verified in C3A, converts
this into original-checker acceptance. No checker implementation is changed.

## 7. Actual upper and tightness

The new file `ActualFunction.ProximalGradientRateAll.lean` applies the already
verified C2/C3A interfaces with `upperCertQ_check_all n`.

completeness assumption is introduced. The Hilbert upper and one-dimensional
