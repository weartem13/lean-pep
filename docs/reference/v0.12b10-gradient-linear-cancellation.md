# v0.12B10 arbitrary-`N` gradient-linear cancellation

Status: kernel-verified with Lean 4 / mathlib v4.31.0.

## Scope

v0.12B9 is kernel-verified.  It proves the exact triangular support of every
generated reverse-LDL square factor and reduces the gradient-linear square sum
at sampled index `r` to

```text
gdGradientSquareContributionQ N r r
  - 2 * gdGradientConstantSuffixQ N r.
```

This slice closes that coefficient family for every trajectory length.  It
does not modify certificate data, interpolation multipliers, square weights,
affine-square factors, the checker, or finite-GD semantics.

## Strict suffix telescope

For a nonfinal sampled-gradient index `r`, the strict suffix is

```text
gdGradientConstantSuffixQ N r
  = sum over k with r < k of gdConstantContributionQ N k.
```

The v0.12B7 constant contribution theorem writes every nonfinal summand as an
adjacent difference

```text
gdConstantTailQ N k - gdConstantTailQ N (k + 1),
```

and the final summand as `gdConstantTailQ N N`.  The restricted finite sum
therefore telescopes to

```text
gdGradientConstantSuffixQ N r
  = gdConstantTailQ N (r.val + 1).
```

The implementation proves a generic finite-range strict-tail telescope and
then transports the generated `Fin` sum to that natural-number statement.

## Local rational cancellation

For `r < N`, the star weight uses its nonfinal branch, the diagonal square
weight uses its nonfinal branch, and the strict suffix is the tail at `r + 1`.
After exact natural-to-rational cast normalization, the remaining identity is

```text
starWeight(r)
  + diagonalSquareContribution(r)
  - 2 * constantTail(r + 1)
  = 0.
```

This is discharged by exact field normalization and ring arithmetic.  The
final sampled-gradient index was already closed in v0.12B9 because its strict
suffix is empty and its final star weight cancels its final diagonal square.
