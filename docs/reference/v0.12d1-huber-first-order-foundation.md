## Purpose of D1

D1 starts that independent lower-bound chain with a one-dimensional one-sided
Huber-type function.  For a threshold `a : ℝ`, define

```text
H_a(x) = x^2 / 2                 if x <= a,
         a*x - a^2 / 2           if a <= x,
```

and

```text
G_a(x) = min x a.
```

The two function formulas agree at `x = a`.  The new module is

```text
LeanPEP/ActualFunction/HuberWitness.lean
```

## Exact first-order contract

The module proves directly, by the four branch combinations for `x` and `y`,

```text
H_a(x) + G_a(x) * (y - x) <= H_a(y)
```

and

```text
H_a(y) <= H_a(x) + G_a(x) * (y - x) + (1/2) * (y - x)^2.
```

These scalar identities are then packaged as

```lean
firstOrder (a : ℝ) :
  IsOneSmoothConvexFirstOrder (huberFunction a) (huberGradient a)
```

without using a numerical solver, a finite PEP witness, interpolation
completeness, or a new certificate.

## Parameterized threshold

For a trajectory length `N`, D1 defines

```text
threshold N = 1 / (2N + 1)
witnessFunction N = H_(threshold N)
witnessGradient N = G_(threshold N)
witnessPoint N k = 1 - k * threshold N.
```

The real threshold is proved to agree with the cast of the exact rational
`gdCenterQ N` used by the verified upper certificate.  The module also proves:

```text
0 < threshold N
witnessGradient N 0 = 0
witnessFunction N 0 = 0
witnessFunction N 0 <= witnessFunction N x
```

so zero is a stationary global minimizer of every parameterized witness.

## Boundary

D1 does not yet prove:

- `HasDerivAt`/`HasGradientAt` for the piecewise function;
- `LipschitzWith 1` for the clipped gradient;
- membership in `IsOneSmoothConvexAnalytic`;
- that `witnessPoint N k` equals the actual GD recursion;
- the exact final value `1 / (4N + 2)`;
- general `L,R` lower-witness scaling; or
- the final tight actual-function worst-case theorem.

v0.12D2 is now kernel-verified: `HuberWitnessTrajectory.lean` identifies the
explicit points with the actual unit-step recursion and proves exact
attainment.  v0.12D3 implements analytic regularity as a separate source
candidate so derivative/Lipschitz proof failures do not obscure the already
verified trajectory algebra.
