# v0.12B1: general smoothness and radius scaling

## Goal

v0.12A proves the normalized actual-function theorem

```text
f(x0 - g(x0)) - f(xStar) <= 1/6
```

for a globally convex function with actual `1`-Lipschitz gradient, a stationary
reference point, and squared initial radius at most `1`.

v0.12B1 transports that theorem to a positive smoothness constant `L` and a
nonnegative radius parameter `R`:

```text
f(x0 - (1/L) • g(x0)) - f(xStar) <= L * R^2 / 6.
```

The implementation reuses the accepted normalized certificate. It introduces
no new PEP profile, primal witness, dual matrix, or rational certificate.

## General analytic and first-order interfaces

`LeanPEP/ActualFunction/GeneralSmooth.lean` defines:

```text
IsSmoothConvexAnalytic L f g
IsSmoothConvexFirstOrder L f g
```

Here `L : ℝ≥0`. The analytic contract records:

- `HasGradientAt f (g x) x` for every `x`;
- global convexity; and
- `LipschitzWith L g`.

The first-order contract records the exact inequalities

```text
f(x) + <g(x), y-x> <= f(y),

f(y) <= f(x) + <g(x), y-x>
          + (L/2) <y-x, y-x>.
```

The file proves the supporting-hyperplane lower model and the general descent
upper model from the analytic assumptions, then packages them as
`IsSmoothConvexFirstOrder L f g`. The proof is the same affine-line argument
used in the verified normalized bridge, with the Lipschitz constant retained
symbolically.

The existing normalized interfaces embed at `L = 1` through:

```text
IsOneSmoothConvexAnalytic.toSmooth
IsOneSmoothConvexFirstOrder.toSmooth
```

## First-order certificate entry point

`LeanPEP/ActualFunction/OneStepScaling.lean` first exposes normalized
certificate transport directly from `IsOneSmoothConvexFirstOrder`. It rebuilds
the same actual-vector Gram datum, PSD proof, ordered interpolation constraints,
one-step model realization, and radius assumption used by v0.12A4. This avoids
re-proving differentiability for the normalized function.

The principal normalized first-order theorem is:

```text
IsOneSmoothConvexFirstOrder.oneStepGD_upper_at_update
```

## Scaling construction

For `L > 0`, `R > 0`, and reference point `xStar`, define:

```text
X(z)    = xStar + R • z,
fhat(z) = (f(X(z)) - f(xStar)) / (L * R^2),
ghat(z) = (1 / (L * R)) • g(X(z)).
```

Exact field and inner-product algebra proves that the `L`-first-order models
for `(f,g)` become the normalized first-order models for `(fhat,ghat)`.
The normalized initial point is

```text
z0 = (1/R) • (x0-xStar).
```

Its squared norm is at most `1`, and its normalized unit-gradient update maps
back exactly to

```text
x0 - (1/L) • g(x0).
```

The `R = 0` branch is handled separately: the radius hypothesis forces
`x0 = xStar`, and stationarity makes the conclusion immediate.

`v4.31.0` toolchain:

```text
lake build LeanPEP
Build completed successfully (3198 jobs).

lake env lean tests/lean/smoke/V12B1SmokeTest.lean
```

The smoke test exposed and applied the complete theorem surface above.  The
remaining output consisted only of tactic-style linter warnings.  A complete
clean release gate should still be recorded from a committed or temporary
clean baseline:

```bash
bash tools/release_gate.sh
```

The result is a universal one-step upper theorem. It does not prove an
actual-function exact worst-case value, the arbitrary-`N` theorem, or
interpolation completeness.
