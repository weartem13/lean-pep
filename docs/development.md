# Development and preservation

Maintain this working tree; public exports are generated by `scripts/export.py`, never edited as a second source tree. Keep new numerical runs and consumer outputs outside source. The author workspace also retains the independent manuscript project; code exports omit it.

Public history starts with an independent root commit, then accumulates reviewed milestone releases in the same repository. The maintenance Git history remains private and intact. See [releasing.md](releasing.md) for fresh code exports, comparisons and protected public-history updates.

## Preserved inputs

Raw captures, selected dual/primal certificates, PSD witnesses, required fixtures and generated Lean modules under LeanPEP are research/proof inputs. They are retained even when named generated or Imported. `data/fixtures` is the complete legacy fixture collection; `data/cases` separates algorithm, horizon and certificate role. Neither selected/raw data nor dependency caches are default cleanup targets.

## Tests and deterministic generation

Run `python3 scripts/test_python.py --list` for every discovered ID. Tests reside in the tests.python package. A single documented compatibility boundary in that runner exposes existing standalone tools imports, with no external PYTHONPATH or per-test sys.path modifications. The 1163 original test IDs map bijectively to their prefixed IDs; ten earlier outer tests and new wrapper safety tests are retained separately. Mathematical assertions and numerical expected values are unchanged.

`python3 scripts/check_generated.py --output "$OUT/generated"` copies required source/fixtures into an external snapshot and runs the existing deterministic shell there. It compares retained generated Lean bytes and input data without writing back to the maintained tree. Path-only metadata changes are recorded explicitly; coefficient/proof changes are failures.

The full runner stages data prerequisites, ten dense regression modules sequentially, the complete aggregate and its uncovered modules before all 73 smokes and independent Replays. Do not remove imports or tests to reduce time. Logs contain exact argv/cwd/exit; timeout and failures are reported, not silently skipped. Full tests use requirements-test.txt; optional live capture dependencies remain separate and no solve is needed for maintenance.

## Rebuildable outputs

`python3 scripts/clean.py` lists only project `.lake/build`, `paper/build`, and Python bytecode under tools/tests/scripts. Add `--apply` for that explicit plan. Symlinks and protected input names are rejected; archives, data, source, the original virtual environment and `.lake/packages` are never traversed for deletion. The safety tests demonstrate refusal and preservation.

Historical reports, original logs, frozen ZIPs, old paper drafts and obsolete runners are privately archived with a migration map. Public historical logs are explicitly labeled path-redacted derivatives linked to original byte hashes. Current execution logs are exported separately from source so packages do not include themselves.
